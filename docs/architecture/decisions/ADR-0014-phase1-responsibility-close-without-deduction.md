# ADR-0014：第一阶段 N08 关闭返工业务但不生成供应商扣款计划

日期：2026-08-16  
状态：已采纳

## 决策

N07 对每道工序只记录一个主责任方；共同责任保留为版本说明，不再在第一阶段录入比例或金额分摊。外部责任按默认倍率 1.2 处理。

N08 由老板确认或驳回。确有例外时，老板可在折叠区填写外部责任特殊倍率及原因；系统把它作为与老板签字绑定的不可变审批快照。N08 同意后返工业务订单关闭。

本阶段不在 N08 自动创建供应商计划扣款、扣款台账或修改供应商计划扣款基数。临时工工资系数和 N08 特殊倍率均不会在周一业务确认前传入供应商扣款计算。

## 原因

订单和跟单的识别方式、以及临时工加价是否进入供应商扣款，仍待业务确认。先完成责任决策与返工业务闭环，避免猜测扣款对象或金额。

## 后果

- N08 特殊倍率有审计记录，但不会在本阶段重算供应商扣款金额。
- 后续扣款 PR 必须显式读取经过确认的扣款基数；不能把工资或审批快照直接当作供应商计划扣款。
- 钉钉、跟单归属、供应商扣款执行继续排除在本 PR 外。
