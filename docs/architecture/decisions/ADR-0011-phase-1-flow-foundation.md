# ADR-0011：第一阶段流程优化的计划与核价分离

日期：2026-08-16  
状态：已采纳

## 决策

N02 保存工序和预估数量后直接进入 N03。N02 不保存业务单价、不创建 IE 待审任务。工序配置中的单价允许为空，以明确它尚未在 N02 定价；N05/N06 将在后续 PR 中负责最终定价与 IE 核价。

## 原因

现场的返工安排先需要“做什么、多少量、谁来做”。价格确认发生在工人最终数量明确之后。把 IE 放在 N02 会增加等待和误解，且不能满足临时工旺季系数的业务需要。

## 后果

- 旧的待 IE 审核记录仍可读取和处理；新流程不再创建该状态。
- 计划确认后先不允许在 N02 改计划，避免已进入人员分配后产生无审计的变更。
- 工序单价为空的订单不得沿用旧的按单价即时算工资逻辑；该逻辑会在 N04/N05/N06 重构中替换。
- 本决定不涉及钉钉通知、跟单归属或供应商扣款基数。
