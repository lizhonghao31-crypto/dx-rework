# ADR-0005：工序配置、IE审核与配置版本

- 状态：已接受
- 日期：2026-08-02
- 对应路线：PR-06

## 决策

1. 每次保存工序配置都生成新的不可变配置版本；草稿被再次保存时只会被标记为已替代，绝不覆盖历史行。
2. 返工单状态仅在提交和IE审核时推进：待配置工序 → 待IE审核 → 待分工；IE驳回初次配置退回待配置，驳回已生效配置的变更单退回待分工。
3. 每道工序分别保存计划数量、计价单位和单价。件必须为整数；小时截断至2位小数；单价截断至3位小数，不四舍五入。
4. 自定义工序可立即用于本次配置；IE通过时，在同一事务内创建带稳定代码的公共工序并建立来源映射。未通过、驳回或草稿中的自定义工序绝不进入公共目录。
5. 已生效配置只能通过带原因的新变更单重新进入IE审核；旧配置在新变更通过后标记为已替代，保留全部原始事实。
6. 尾部主管仅可配置，IE仅可审核；两类角色都不能读取品控草稿。所有写入与返工单状态、审计事件、消息发件箱、幂等记录处于同一事务。

## 影响

优势：数量、单价和审核结论可逐版本追溯；自定义工序不会污染公共目录；重复点击、并发提交与越权写入不会形成重复生效配置。

代价：每次保存草稿都产生版本记录，查询需默认展示最新有效版本；已生效的改价不能原地编辑，必须填写变更原因并再次经过IE审核。

## 排除项

不实现PR-07的工人分配、计件上数、金额计算或成员快照；不实现责任判定、扣款、工资或ERP接入。
