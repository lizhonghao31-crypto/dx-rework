# ADR-0017：尾查并行报数与逐工序交叉核验

日期：2026-08-18  
状态：已采纳

## 决策

1. N02 由尾部主管配置工序和待 IE 核价单价，并在最终提交时指定一名或多名尾查；箱数/范围为可选辅助信息。
2. N02 提交后，尾查即可独立提交实物报数；该任务不等待 IE 审核、工人分配或工人完工上数。
3. N03 只审核工序与单价；通过后才可进入 N04 分配工人，N05 改为工人完工上数。
4. N05 与 N06 尾查报数并行。两边所有有效任务均完成后，订单进入 N07“尾部主管整单确认”。
5. N07 按工序核验：有效工人上数总和必须小于或等于有效尾查数量总和。小于允许并显示差额；大于必须先驳回并调整工人上数或尾查报数。工资只由有效工人上数计算。
6. 新写入的返工计件单位统一为“件”；历史小时记录保持只读可查。
7. 计划数量、数量增减、跟单确认与 IE 数量复核退出运行时流程；历史记录保留为审计证据，禁止产生新调整。

## 一致性与退回

- 每名尾查人员仅能提交本人有效分配的一份报数，且每道工序数量不得超过该人员的返件总数。
- IE 退回 N02 时，系统以独立审计事件撤销旧尾查分配及其报数参与资格；重提配置后必须重新分配尾查，避免旧工序或旧数量混入。
- 工序在 N02 提交后锁定；本轮不允许在已进入人员分配后修改工序，避免跨配置混算。

## 非范围

- 钉钉待办文本、推送时机与外部卡片改造留给钉钉专项。
- 临时工实发系数、外部扣款倍数、责任选择及工资结算规则不在本 ADR 中改动。
