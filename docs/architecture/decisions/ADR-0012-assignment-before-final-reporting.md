# ADR-0012：先完成人员分配，再一次性完工上数

日期：2026-08-16  
状态：已采纳

## 决策

N03 将每个被分配人员保存为独立任务，但不在首次分配时启动返工。尾部主管确认每道工序至少有一名人员后，统一进入 N04。

N04 只记录每个独立任务的一次最终数量。正式工只可为本人提交；尾部主管凭既有代录权限只可为临时工批量代录。提交不创建工资金额或使用 N02 预估数量做上限。

## 原因

现场按纸面计数，工人不需要理解累计上数或计件金额。独立任务确保正式工和临时工都可逐人留痕，且相同姓名临时工能通过稳定编号区分。等待完整分配再开工避免分工未完成就被执行状态锁定。

## 后果

- N04 全员上数后流转 N05；后续 PR 在 N05 填写单价与临时工调整系数，在 N06 由 IE 审核。
- N02 预估数量仅保留为安排参考，不成为上数上限。
- 当前报工金额为 0 的待核定记录，旧的即时工资分摊逻辑不再用于新流程。
- 本决定不改变供应商计划扣款、钉钉通知或跟单归属。
