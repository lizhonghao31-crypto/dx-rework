# ADR-0007：收货看板日期范围与分批展示口径

- 状态：已接受
- 日期：2026-08-28
- 对应范围：订单看板收货统计

## 决策

1. 订单看板使用开始日期和结束日期进行闭区间查询，日期边界统一按 Asia/Shanghai 自然日计算；款号搜索始终限制在所选日期范围内。
2. “期间实收数量”和期间次品只统计所选范围内的收货事实；“原收货”显示开始日期之前的累计实收。
3. 差异显示截至结束日期的累计实收减固定送货单总数，因此本期收货会立即计入仍少收或多收的结果。
4. 独立“收货次数”列取消；固定送货单数量区域显示截至结束日期的“第 N 次收货”。
5. 用户可见的“收货单数量/图片/附件”统一更名为“送货单数量/图片/附件”，内部字段名和历史审计事实不改写。
6. 订单卡片现有尺寸、信息密度和整体布局保持不变，只替换获批字段与日期筛选控件。

## 影响

管理人员可以查看任意日期范围内的订单和 KPI，并清楚区分范围前已收、本期实收与截至范围结束日的真实差异；仓管收货页面的操作步骤保持不变。

## 排除项

本决策不处理 Root 错款号归并或送货单图片替换，不改变返工状态机、收货权限和历史原始事实。
