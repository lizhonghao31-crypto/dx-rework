# ADR-0018：N01 图片凭证与工资口径完整性

日期：2026-08-18  
状态：已采纳

## 决策

1. 手工创建的返工单在 N01 提交前必须已经绑定至少一张状态为 `ready` 的 JPEG、PNG 或 WebP 验货/问题图片。PDF 不满足该必填条件。
2. 该规则由页面提示、服务端归属校验和数据库状态迁移触发器三层共同保证；任一层均不能通过直接更新绕过。
3. 工资的临时工实发系数只读取 N07 尾部主管整单确认时落库的 `rework_tail_completion_coefficients`。工资明细与 Excel 导出使用同一事实来源。
4. 工资计算继续且只能使用“IE 核准单价 × 有效工人上数 × 临时工实发系数”。外部扣款倍率不参与工资计算或显示为工资系数。
5. 财务报表页面按两位小数展示金额，不再以整数四舍五入隐藏分。

## 后果

- 旧返工单和历史附件保持可查；仅新的手工 N01 提交受硬性图片规则约束。
- 未上传图片、仅上传 PDF、附件未就绪或归属不符，均不能进入 N02。
- N07 外部扣款倍率仍由张文豪在责任环节按默认不低于 1.2 的规则调整，但它与工资表和工资导出没有数据连接。
