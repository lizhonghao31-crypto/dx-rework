# ADR-0008: Root 收货纠错合并与图片替换

- 状态：Accepted
- 日期：2026-08-28

## 决策

Root 仅可在来源批次和目标批次均从未发起返工时进行以下纠错：

1. 把错款号改成已有有效款号时，系统自动把来源批次合并进目标批次。
2. 目标批次沿用原送货单总数；来源批次的有效实收、次品数量累加到目标批次。
3. 每条原始收货事实的数量、收货人和时间不改写，只在受审计保护的事务中重绑批次。
4. Root 可选择 1–3 张新图整体替换当前送货单图片；旧图仅退出业务展示，文件与退役审计永久保留。
5. 来源批次逻辑删除；合并、来源删除、图片替换均记录独立 operation event。

## 权限与失败边界

- 必须同时具备 `root_superuser` 与 `receiving:correct`。
- 普通仓管、质检、生产管理、老板均不能使用该纠错入口。
- 任一批次存在返工历史、版本冲突、图片非本人上传或图片已绑定时，整个事务回滚。
- 未选择新图片时仅纠正/合并数据，不改变现有图片。

## 展示

看板和返工业务详情排除已退役图片；审计数据与原对象不删除。合并后看板只显示目标批次一行，原始收货次数与逐次事实仍可追溯。
