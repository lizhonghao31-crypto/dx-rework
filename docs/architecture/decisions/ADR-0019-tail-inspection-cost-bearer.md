# ADR-0019: 整查费用承担与工资对数职责分离

- 状态：Accepted
- 日期：2026-08-29

## 背景

“是否需要整查”只决定是否进入整查执行，不能推导费用由谁承担。年加工合同未覆盖尾部费用时由本厂支付；回货返工且需要整查时应由加工厂承担。此前判责引擎固定排除整查工序，导致加工厂全责订单的整查工资未进入外部责任金额。

财务当前只使用工资报表对数，不在系统执行工资月结；但既有月结能力可能在未来复用。

## 决策

1. N01 在选择“需要整查”时，必须同时选择“本厂”或“加工厂”承担整查费用；选择“不需要整查”时不显示该字段并跳过整查流程。
2. N01 的承担方是质检初判。N07 默认展示该初判并由生产主管随责任判定一并确认，不要求重复选择；只有初判有误时才显式进入“修改承担方”，纠正与责任草稿在同一审计事件中保存。
3. 本厂承担时，整查工资仍计入工资报表，但不进入外部责任基础。
4. 加工厂承担时，整查工序进入责任基础，并由服务端强制加工厂 100%、倍率 1.2、供应商为订单加工厂。
5. 现有订单默认回填为本厂承担；HO20544223 / RW-2026-0826-001 回填为加工厂承担。
6. 停止生成工资月结待办，当前界面隐藏月结状态和锁定动作；月结表、服务和接口保留，便于未来恢复结算职能。
7. N07 可勾选多道普通工序，将同一组责任方、比例、供应商和倍率批量填入；批量操作只更新页面草稿，仍由既有“提交责任判定”统一校验和保存。整查承担方是订单级事实，不参与工序批量覆盖。

## 结果

费用判定由显式业务事实驱动，不再从“需要整查”或加工厂责任比例间接推断。整查工资和外部扣款可分别核对，月结能力也不会被不可逆删除。
