# ADR-0006：老板终判责任时同步确认本厂承担

- 状态：已接受
- 日期：2026-08-10
- 决策人：产品负责人 Eric
- 适用范围：N07 责任判定与 N08-A 本厂承担审批

## 背景

现有流程无论由谁完成 N07 责任终判，只要存在本厂承担金额，都会再向老板权限组生成一项 N08-A 审批。老板本人接管并完成责任终判时，这会要求同一人对同一份不可变责任快照再次确认，形成重复待办和重复点击。

生产管理角色完成责任判定时，仍需要老板独立确认本厂承担金额；这项职责分离必须保留。

## 决策

当责任终判人具备数据库校验通过的直接有效 `owner_group` 角色和 `own_factory:approve` 权限时：

1. 仍创建绑定正式责任版本的本厂承担审批快照，保留金额、来源和审计历史。
2. 在同一事务中由该终判人同步写入“已批准”决定。
3. 不生成“待本厂审批”的个人待办和待处理通知。
4. 其他老板只接收终局结果通知。
5. 如果不存在外部责任分支，返工单可直接完成；如果仍有外部责任，则继续等待对应供应商/应付处理。

当终判人不是直接有效老板（例如生产管理角色）时，现有独立老板审批保持不变。订单范围代理不触发同步批准，以免把临时授权扩大为“终判即批准”。

## 一致性与失败处理

- 同步批准复用既有审批决定写入、权限函数、不可变触发器和操作事件，不绕过审计约束。
- 创建责任正式版本、创建审批快照、同步批准和后续状态推进位于同一数据库事务；任一步失败则整体回滚。
- 不修改历史迁移，不改变已存在审批记录。

## 后果

- 老板本人终判不再收到重复审批任务。
- 生产管理人员终判仍保持职责分离。
- 报表继续从审批快照读取本厂承担金额，不会因取消重复动作而丢失财务事实。
