# ADR-0006：分批收货共用固定送货单总数

- 状态：已接受
- 日期：2026-08-28
- 对应范围：收货分批数量口径

## 背景

同一款号可能分多次送达，但业务只提供一张写有整批总数的送货单。仓管在每次收货时仍按现有表单填写该送货单总数、本次实收和本次次品；不能要求仓管判断首次或续收，也不能把后续重复填写的送货单总数再次累加。

## 决策

1. 同一有效收货批次只保存一个固定的送货单总数，以首次收货填写值建立。
2. 同批次后续收货继续保存每次仓管填写的原始送货单数量、实收和次品事实，但业务汇总只累计实收与次品，不累计后续重复填写的送货单总数。
3. 差异统一计算为“累计实收－固定送货单总数”；每次原始输入继续不可变并可审计。
4. Root 在发起返工前可按既有审计流程修正固定送货单总数及累计数量；发起返工后仍禁止修改。
5. 现有历史批次按上线前有效口径回填固定送货单总数，不改写任何历史收货事实。

## 影响

仓管操作保持不变；管理看板可以正确表达分批收货，不会因重复填写整批送货单总数造成少收误判。系统增加批次级固定总数字段，并保留收货事实级原始输入用于审计。

## 排除项

本决策不改变补录规则、收货图片规则、返工状态机、权限或仓管表单步骤；日期范围 KPI、错款号归并和图片替换由后续独立 PR 实现。
