# ADR-0013：尾部定价与临时工系数必须经 IE 审核后生效

日期：2026-08-16  
状态：已采纳

## 决策

N05 把实际完成数量、每道工序最终单价及“临时工 + 工序”的调整系数作为同一份尾部定价方案提交。所有临时工默认系数为 1.0，非 1.0 必须写明原因。

N06 的 IE 角色只可通过或驳回该方案。通过时才将单价写入已审批工序、将逐人报工金额固化，并创建后续责任判定需要的审核快照；驳回时不改动数量或价格，订单返回 N05 重新提交。

## 原因

预估数量是现场安排参考，实际数量可能高于或低于预估，不能作为 N04 的拦截条件。价格与临时工旺季加价需要可追溯、可复核的审批边界，且不应在工人上数时影响理解。

## 后果

- 新流程禁止跳过 N05/N06 直接从完工上数进入责任判定。
- 正式工与临时工都按独立人员任务保留金额基础；临时工系数只影响其工资，不改变供应商计划扣款基数。
- 钉钉通知和跟单归属仍不在本决策范围内。
