# ADR-0015：多次收货来源分类与送货单累计

- 状态：已接受
- 日期：2026-09-03
- 替代：ADR-0006
- 对应范围：收货分批数量口径

## 背景

原规则假设所有续收都共享首次送货单总数。实际业务同时存在两种事实：嘉顺分批送达时总数不变；其他工厂再次送货时会产生新的送货单数量，必须累计。普通收货继续写入已有批次会绕过这项选择，导致仓管无意中使用错误口径。

## 决策

1. 多次收货先选择来源：`嘉顺收货` 或 `其他工厂收货`。
2. 嘉顺收货沿用固定送货单总数，只追加实收数量和次品数量。
3. 其他工厂收货必须填写本次送货单数量；该数量与实收、次品在同一事务中追加，批次送货单总数同步增加。
4. 普通收货发现未关闭的同款收货批次时，前端提示并跳回多次收货；服务端同时拒绝写入，防止绕过。
5. 每次收货保存来源事实。上线前已存在记录标记为 `legacy`，不自动推断或改写。
6. Root 对历史每次收货的逐笔修正、人工判定 legacy 来源和修正审计，属于后续独立 PR，不在本决策的首次交付范围。

## 影响

嘉顺仓管继续按旧步骤操作；其他工厂只多填一次本次送货单数量。订单看板、差异和 KPI 使用批次累计送货单总数，避免将其他工厂的新增送货误判为少收。

## 排除项

本决策不修改补录规则、返工状态机、收货图片规则、Root 历史逐笔修正权限或既有收货事实。
