## PR01完成标准

1. 一次老板批准按真实款明细生成任务，多款不遗漏。
2. 重试、重复请求、合同换版或款号修订不重复建任务。
3. 正式款号与代用号在裁床投影中严格区分。
4. 裁床主管/工人角色与能力已注册，但不自动赋给真人。
5. 安全投影不泄漏价格、金额、银行/合同敏感数据。
6. 外发给价、生产管理决定、老板批准、合同、转厂和财务独立性回归通过。
7. 当前Head Full Gate全绿并完成一次Codex Review后，才达到可合并条件。

## 历史与生产边界

PR01迁移不扫描、补造或改写历史实裁。生产库实际历史覆盖率在未取得生产数据操作授权前保持“未核验”。生产补建属于后续切换动作，不由代码迁移擅自执行。
