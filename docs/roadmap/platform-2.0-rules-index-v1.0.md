1. 根目录 `AGENTS.md`；
2. `docs/governance/chatgpt-codex-construction-workflow-v1.0.md`；
3. 本索引；
4. 本次任务对应的唯一业务规则；
5. 任何 UI 工作补读 `docs/requirements/rework-ui-golden-source-v1.0.md`；合同工作补读 `docs/requirements/sourcing-contract-field-audit-v1.1.md`。
6. GitHub 最新 `main`、开放 PR、当前 Head、CI 和 Review 状态。

不得用旧聊天中的 SHA、PR 状态和口头摘要代替 GitHub 当前事实。

## 3. 路线隔离规则

### 3.1 外发供应商路线

任务出现以下任一内容时，必须读取外发供应商规则：

- 外发定价、IE 审价、生产管理选厂或老板审批；
- 达兴价格、多款号、多颜色或逐款价格；
- 供应商中心、供应商资料；
- 合同 PDF、合同编号、财务核对、正式派单；
- 生产数据填报、实时生产看板、双进度、预警；
- 我的待办“实时生产”或发货/回货联动。

不得读取样衣规则来补充上述业务含义，也不得沿用旧 ERP 数据接入设想。

### 3.2 样衣路线

任务出现样衣台账、建档、借出、归还、扫码确认、处置、采购金额或样衣迁移时，必须完整读取样衣迁移规则。

样衣 PR 不得修改外发、供应商、合同或生产状态；外发供应商 PR 也不得修改样衣领域表、状态、迁移或权限。

### 3.3 共享平台能力

两条路线可以复用现有平台能力：

- 钉钉身份与稳定用户 ID；
- capability 授权；
- 我的待办基础设施；
- operation events / outbox / 幂等；
- OSS 附件；
- 共享 UI token、组件、分页、弹窗和导航壳。

若一个改动确实必须修改影响两个路线的共享基础设施：

1. 不得夹入任一业务 PR；
2. 单独建立“共享平台基础 PR”；
3. 明确两条路线的回归范围；
4. 执行 Full Gate；
5. 当前 Head 全绿后由业务负责人决定是否触发一次 Codex Review；
6. 合并后两条路线分别从最新 `main` 继续。

## 4. 规则优先级

发生冲突时按以下顺序判断：

1. 平台安全策略与仓库 `AGENTS.md`；
2. `docs/governance/chatgpt-codex-construction-workflow-v1.0.md`；
3. 当前任务对应的业务 Golden Source；
4. 本索引中的范围和进度；
5. 最新 `main` 的已交付代码事实；
6. 历史路线、旧 PR 描述、ERP 实现和聊天记录。

业务规则与当前代码不一致时，不能擅自选择一边：应先报告具体冲突，按 Golden Source 的 PR 计划增量修正代码。仅 UI 实现细节与旧截图冲突时，以业务规则指定的现平台设计来源为准。

## 5. 历史文档处置

`docs/roadmap/platform-sourcing-roadmap-v1.0.md`记录截至 2026-08-31 的平台与报价选厂历史施工。该文档包含已经由 2026-09-04 新规则取代的 ERP 数据源、合同范围和后续 PR 计划，因此：

- 只作为历史交付记录；
- 不再是新窗口当前路线入口；
- 不得用其旧结论覆盖 `sourcing-supplier-production-v1.0.md`；
- 已交付代码事实仍保留，新路线从最新 `main` 增量演进，不回滚历史 PR。

## 6. 新窗口可使用的简短指令

### 6.1 继续外发供应商路线

> 阅读“平台建设2.0规则索引”和“外发供应商生产规则”，核验最新 main 与开放 PR，然后从下一未完成的 SSP PR 继续施工。不要重新讨论已冻结问题。

### 6.2 启动样衣路线

> 阅读“平台建设2.0规则索引”和“样衣系统迁移规则”，核验最新 main 与开放 PR，然后按样衣规则从下一未完成 PR 施工。不要读取外发规则推导样衣业务。

对应文件：`docs/requirements/sample-system-migration-v1.0.md`。

### 6.3 只查询当前进度

> 阅读“平台建设2.0规则索引”、对应业务规则、最新 main 与开放 PR，只报告当前状态、下一步和真实阻塞，不施工。

## 7. 进度更新纪律

- 某个业务 PR 合并后，应在对应详细规则或独立路线状态文件中记录完成情况；本索引只更新到“当前下一步”，不复制全部 PR 细节。
- 业务负责人尚未启动的路线保持“未开工”，不能因为另一条路线施工而自动启动。
- 不允许同时为两条路线创建会修改相同共享文件的业务 PR。
- 用户说“停”后立即停止，不得切换到另一条路线继续施工。
