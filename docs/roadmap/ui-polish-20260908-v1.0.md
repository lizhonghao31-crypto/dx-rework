# 全系统紧凑 UI 与交互修复施工计划 V1.1

业务负责人于 2026-09-08 同意方案并指示开始。承接功能建设1.5.5，优先全系统紧凑度与精致度，按五个独立 PR 实施。此前十三 PR 路线是历史背景，不作为本轮未完成清单。

## 统一设计约束

- 沿用现有字体、调色盘、线性图标与控件体系；主要动作、次要动作、状态标签、模块切换和折叠入口按用途区分。
- 标题至主体默认 12px；清除模块重复外边距，保留页面外边距和移动底部安全区。
- 卡片轻阴影，嵌套卡片以细边框分层；不得靠压小正文或触控区提高密度。
- 普通按钮至少 40px，移动主要提交至少 48px；输入桌面 42px、手机 48px/16px；待办切换移动至少 44px。
- 装饰限同套线性图标、选中标记、数量徽标、细分隔线、简洁空状态和克制反馈；不添加大幅插画或持续装饰动画。
- 大型展开按钮改为紧凑标题行，保留完整文字、键盘操作、焦点与展开状态；展开内容、二级操作和筛选也要检查空间。
