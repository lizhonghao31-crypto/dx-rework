## 交接边界

| 节点 | 本次处理 |
|---|---|
| 核料→纸样、纸样→裁板、裁板/无工艺→车板 | 原显式业务完成与前置保持，不扩展自动流转 |
| 工艺执行→设计师确认 | 保留人工业务决定 |
| 工艺确认→尚未创建的文员纯转交→车板 | 合并为系统路由事件；使用已安排人员，失效/未指定则待安排；不记收料时间 |
| 已存在车板转交任务 | 保留原操作和历史，不删除、不重写 |
| 车板实际接收 | 新合并路由仍要求本人原 handover 动作，系统事件不满足该条件 |
| 送洗/洗水/尾查/设计确认/寄样 | 保留真实物流、失败/退回、最终确认及快递事实 |
| 问题面料停用、复版 | 原有权决定与版本、继承证据继续生效 |

人员与正式归属同时确认时，同一个 PostgreSQL 事务调用原 native assign，沿用原权限、金额/类别/版本、工资分段、待办刷新。旧客户端未显式 opt-in 改派仍拒绝覆盖已有负责人。没有改变工资公式、责任或已完成历史。

新增 0245 仅扩展任务成果用途约束；纸样成果必须关联 task_id。迁移 manifest 与低权限部署前置清单同步更新。无历史数据回填。
