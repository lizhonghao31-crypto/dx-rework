# 第二轮复测 PR01：多 PO 首次装箱

依据《第二轮复测报告（未通过）_20261007》及 2026-10-08 用户授权，目标验收分支为 `release/digital-production-v1`，采用 FULL 门禁。用户负责部署。

根因：看板/API 按开裁单分组，0190 数据库装箱 guard 却按整个款号判断已录，导致独立开裁组间首次装箱互相阻断。以追加 0234 migration 对齐分组锁与 guard，不修改任何已应用 migration、历史数量或权限。
