## 业务

预派纸样、裁板、车板单人主办；预派不创建提前计时的任务。核配通过校验本轮主配料的实物、数量、颜色、规格，随后纸样开始 48h；纸样完成并交出后裁板才开始 4h。辅料不阻断这两个节点。

缺项退回完成首次反馈，但不计生产完成；生成设计师补料事项，补齐主配料到货事实后提交缺项复核。复核默认无 SLA，不修改首次 4h 历史。已通过检查项可沿用，补料复核不是复版。

有印绣花时纸样完工须有工艺开发板；完工事件沿用原通知，仅知会设计师。检测报告保留附件和建议；建议停用必须有总监允许使用决定，后续正常报告不能覆盖未决问题。

随单码可选，复用已有 qrcode；仅包含部署配置对应的稳定任务地址，扫码不写业务、不能跨任务权限或前置条件。没有公网地址配置时保留正常待办查单。

原工资归属、工资转移均不在此 PR 改动。
