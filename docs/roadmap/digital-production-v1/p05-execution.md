## 实现

来源列表和母单详情进入开发单；客户、款号、代用号、开发类型、设计师直接沿用来源。两模板保留原尺寸项，支持添加尺码列及尺寸行；面料保留布行、品名、幅宽、克重、成分、用量，辅料追加本轮适用性与预计日期。原表初版／复版／齐色版按已确认规则覆盖为来源的头版／开发板，复版由 P08 实现。样例值不作为默认。

草稿允许缺项，发布校验数量、样板尺码、下单日期、款图以及本轮未到辅料预计日期；不强制菲林或免工艺订单的工艺开发板。发布冻结原资料并创建一次实际核配任务；唯一有效文员自动指派，多人或缺人沿用现有待指派处理。核配业务办理由 P06 接续。

到货、预计日期调整、辅料代用确认保存追加事实，已发布原表不可覆写；问题面料不走设计师代用确认。提醒仅站内，辅料提前一天、当天、逾期按当前阶段发送，过期创建不回放所有历史阶段；改预计日期不删除原逾期记录。工艺开发板知会仅设计师，到货与缺料提醒仅设计师及技术主管。

附件沿用私有上传服务并绑定来源，不允许挪用其他单附件；查看随来源／已分配任务范围校验。打印使用完整文本而非输入框截图，尺寸和物料明细允许续页。
