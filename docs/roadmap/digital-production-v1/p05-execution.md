到货、预计日期调整、辅料代用确认保存追加事实，已发布原表不可覆写；问题面料不走设计师代用确认。提醒仅站内，辅料提前一天、当天、逾期按当前阶段发送，过期创建不回放所有历史阶段；改预计日期不删除原逾期记录。工艺开发板知会仅设计师，到货与缺料提醒仅设计师及技术主管。

附件沿用私有上传服务并绑定来源，不允许挪用其他单附件；查看随来源／已分配任务范围校验。打印使用完整文本而非输入框截图，尺寸和物料明细允许续页。

## UAT PR05 板房独立视图（2026-10-15）

板房 URL 用 section 区分开发岗位、大货纸样与唛架及历史入口。开发只取真实 development task 七环节，保留权限内全部进度、主管待分派与正式派工；普通工人该视图仍按原 mine 权限只读自己任务。重复的我的任务、人员安排及独立主办筛选移除。一个关键词支持原款号／PO／客户及当前主办姓名，重名靠实际任务和主办ID保留区分，点击查询／回车才发请求，输入法确认不触发提交。

两个列表前后端每页15条，各视图切换清理不适用筛选，详情与刷新保持当前视图／页码／关键词。开发列表只投影原权限内任务的只读卡片事实，完成主办／办理人、条件、风险与KPI保持原语义；点击办理重新读取实际任务和原能力，预览不携带执行授权。大货保留SQL分页，预缩、外发批准、双完成释放开裁和工资账本均沿原模型。
