## 统一状态与点击约束

- 计划日期保留 date 精度，SLA deadline 保留 instant 精度；未启动的计划不启动 SLA。计划未登记须显式保留，不复制合同交期、回版日期或下单时间。
- 完成/取消历史只读；当前可办理由原领域授权决定；无权/未生成/待前置/无 SLA/时间缺失分开。资料或事实缺失不得用参考图样例兜底。
- 原业务入口仍由原模块检查允许/拒绝。Journey URL 不授予权限；历史 `entryId` 指原审计事件，保留原订单与确切节点。
- 本机真实后端截图与浏览器结果记录首阶段公共区域实际效果。完整 Golden 专用布局和线上同 SHA Acceptance 在对应后续阶段核验，不把本地测试/旧 demo/CI 当作通过。
