## 最终行为

`/ui/digital-analysis` 提供产出与积压、节点时效、等待与缺料、复版与质量四个视图。继续使用原分析服务、任务事实、SLA 修订、事件、更正、主办接续、代理、原开发轮次及分析审计记录；没有另建任务状态机、数量账、工资账或评分。

本期新开发按首次原发布日期去重，本期完成及寄样按原完成日期统计。当前积压包含创建日期在所选期间之外的未完成任务。服务端筛选增加日期口径、指标、节点、当前主办、办理周期区间和复版来源；明细、导出和留存依据使用同一筛选及原逐资源技术读取权限。既有调用不传新口径时保留原创建日期语义及 v1 规则版本。

节点时效只把原可判定完成任务纳入 SLA 分母；缺失、补报未核实时间继续排除精确周期。等待沿用原来源区间并集，不把并行区间重复累加，不将办理周期解释为净工时。复版只统计原正式发布轮次，工艺布片同样纳入，保存草稿不计数；展示原分类、影响节点和客户评语或内部问题，链接到原轮次。

指标和节点均可下钻原任务；原任务以 `taskView=read` 打开并保留经过严格校验的本地沙盘返回条件。分析记录保留筛选、任务依据、口径版本、快照时间、拟调整动作与观察时间；导出继续使用原业务导出权限。原成熟模块内部表单、按钮和办理逻辑保持原样，只扩展统一返回入口。
