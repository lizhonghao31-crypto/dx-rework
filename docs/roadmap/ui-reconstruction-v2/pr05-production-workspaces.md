# PR05 产前、裁后工艺与生产展示

基线：release/digital-production-v1，4d6378ff287699aa37e569a4237dc3cf4c24e812。
依据：V2.0 正文 6.4、6.5、9.5；reference-4/5 仅用于区域布局和视觉参考。

范围：新产前准备和裁后工艺工作台、独立生产展示模式。Journey、BulkPreparationSheet、FactoryFlowSheet 和原 ProductionDashboard 是唯一事实来源。公共导航进入新页；原办理页及原实时看板仍保留原控件、数量、权限和管理入口。原页往返保留验证后的本地工作台、筛选和选中订单；没有增加开裁、QC 或发厂命令。

产前显示客户确认、外发报价/批准、有效发布制单、大货纸样/唛架、预缩以及完整开裁汇合。纸样与预缩并行，外发定价在开裁之前。裁后区分物流、QC处理/复查、全部PO、实际发厂及到厂/清点/船样；老板批准时间不充当实际发厂时间。生产展示复用原填报数量、完成时事实与工作日进度，缺失事实明确标识。

验证：3 项边界测试；原 PostgreSQL P11/P12/P13-P14 8 项通过（其余50项未选中）；3 类真实 TEST 浏览器场景、1672/1280桌面布局；成熟板房、外发、裁床、返工复核四页内部正文与控件样式对照；lint、web typecheck、完整 build 和77项静态业务链门禁。最终HEAD的截图与结果保存在消费端材料目录，PR交付评论记录SHA。FULL和一次GitHub Codex Review以最终PR记录为准。

独立本地TEST中通过原外发、合同、发厂和填报服务建立生产夹具。未使用在线订单，未部署、重启或修改线上SQL。无 migration、scripts/infra、根package/lock变更；42b2原工具兼容检查要求全部通过。

限制：未执行移动端或线上Acceptance完整UAT；本地浏览器产前/裁后截图采用尚未发布制单的真实订单，完整并行、全PO、QC和发厂合法/非法链路由原PG用例验证。已知A4同母单任务元数据、仓库todo入口缺陷未宣称修复。
