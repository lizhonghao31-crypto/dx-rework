## 尚缺的计划规则

已查原 schema、领域服务与 v1.1 R37/R38：任务 SLA 在真实进入时计算；其余未确认节点先无 SLA；数字流程不用工作日时钟。原开发物料有预计到货日期及原修订记录，可逐条复用。开发单另有“回版日期”，原规则没有把它定义为每个节点目标，不能自动复制到所有节点。

原系统没有其它未启动节点的独立计划日期。要达到“所有适用流程都有计划/目标时间”，仍需业务负责人明确登记岗位、入口和修订规则。已就这一项提出问题；在明确前不得用下单时间加 SLA、合同交期倒推或生成默认计划。本次对已有物料计划按原记录输出，对未知保持空值；不能据此宣称全覆盖完成。

最小待决问题：本补丁是否先保留无原计划的节点为“未登记”，并明确正文 §4.1 的全覆盖要求未满足？涉及尚未生成的核配/纸样/裁板/工艺/车板/尾查/确认/寄样等任务，以及预算/制单/外发审批、产前准备/开裁、工艺发厂/工厂生产、回货/复核/责任/装箱等节点。已有任务的有效 SLA 继续使用；已有开发物料计划已接入。若本次必须覆盖这些未启动节点，需另明确登记岗位、原入口和修订规则，当前补丁不自行建立计划管理模块。
