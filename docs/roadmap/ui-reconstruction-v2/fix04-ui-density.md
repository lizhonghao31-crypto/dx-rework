# FIX-04 新工作台视觉密度与手机布局

依据：2026-10-06 第一阶段确认范围和补充验收报告。基线为已合并 FIX-03 的 release/digital-production-v1；共享 KPI / SVG 图标能力使用 FULL 门禁和一次 GitHub Codex Review。

新座舱、开发、板房、沙盘与生产展示的指标卡缩小桌面留白，保留原真实数字、标签、解释和下钻。字体不为压缩卡片降到 12px 以下；卡片高度允许内容自然增长。统一使用与导航相同描边契约的装饰 SVG，避免系统字形差异；已有不同环节的颜色保留。

订单详情、产前与发厂详情以真实设计款号作主要标题，原母单编号继续在次要信息中显示。只改变展示层级，不以款号推断跨模块身份，不改跳转资源 ID。流程仍为正文要求的七大流程，外发定价选厂、并行纸样 / 预缩以及开裁原门禁不变。

手机端指标卡分两列、文本可换行、表格和七个流程在局部区域横向滚动；详情分区按可用宽度排列。样衣、外发、返工、生产填报等成熟模块的内部字段、按钮、状态、权限与操作顺序不在改造范围。保留 PR656 的板房桌面完整卡片、七环节可达性、过滤和返回上下文。

验证计划：1280 / 1672 桌面与 390 手机使用原本地 TEST API，检查真实指标未变、SVG 存在、无页面溢出、无指标截断、主标题来源正确；另跑 PR656 三个桌面尺寸原交互回归和六个成熟模块内部比较。最终 SHA、实际截图、测试与 FULL 门禁结果以 PR 交付记录为准。没有新增业务账、批准放行、数据库迁移、部署或线上 UAT；DOC-01–03 尚未开始。
