# UAT 界面闭环决策（2026-08-11）

## 背景

真实 ECS 验收确认：返工上数被错误恢复为一级入口；工资管理仅有月结卡片；员工权限虽有独立路由但系统管理无入口；报表和系统管理仍直接显示技术枚举；全部订单无附件提示；侧栏身份区未稳定贴底。

## 决策

1. 一级导航继续采用订单中心模式；返工上数保留为订单流程节点，不作为一级入口。
2. 系统管理向有权用户显示员工权限管理入口，沿用现有员工目录、授予、撤销、停用、恢复和审计能力。
3. 工资管理首屏提供工人/返工单/款号、日期、本月/本季度/本年度、状态的交叉查询，并显示按工人汇总、逐单逐人明细和 Excel 导出；原月结批次入口继续保留。
4. 财务报表和系统管理的技术状态、动作、角色、权限、布尔值和时间统一转换为中文业务表达；稳定 ID 继续保留用于审计。
5. 全部订单卡片显示已就绪附件数量，点击订单进入既有授权预览/下载区。
6. 侧栏身份区使用视口内弹性布局固定到底部。

## 不在本次范围

- 附件上传性能链路。
- 生产 ECS、钉钉应用和组织权限配置。
- 历史工资与责任金额尾差的数据修复；该问题必须以独立金额规则和迁移验证处理，禁止通过界面改写金额。
