# UI 信息架构收口决策（2026-08-12）

## 已确认决策

### 1. 返工创建唯一入口（2026-09-01更新）

- “返工”模块不再提供独立“发起返工”菜单；桌面端和移动端均只保留“返工单看板”等查询与处理入口。
- “订单回货”看板中未关联有效返工单的收货订单，是创建返工单的唯一入口。
- 创建请求必须携带稳定的收货批次ID；款号由服务端按收货批次读取并在表单只读展示，禁止手工输入、按款号猜测或静默关联最近批次。
- 裸访问或缺少有效收货批次的发起地址必须返回“订单回货”，不得展示空白创建表单。
- 正式提交只在服务端确认成功后清空当前表单、附件预览和本地提交状态，使操作者可以立即录入下一张单据；失败时保留当前填写内容。
- 保存草稿仍属于当前收货订单的填写过程。离开发起页后，草稿与其他已存在订单均从返工单看板进入订单详情。
- 提交后的撤回、取消以及撤回后草稿的修改和再次提交，统一在对应订单详情的 N01 节点处理。既有服务端状态机、权限校验、审计与接口不变。

### 2. 页面标题

- 一级页面统一使用同一左对齐、主标题字号、标题区间距和右侧状态/操作区。
- 标题只保留一行黑色主标题和一行紫色功能说明；不再使用主标题上方的眉题。
- 系统管理、工资管理及其他使用独立标题实现的页面，接入相同标题结构；不在卡片内部另起特殊主标题。

## 不在本次范围

- N08 责任结算、钉钉登录/待办、权限规则、订单状态机、创建来源校验以外的服务端接口和数据迁移。
- 调色盘、组件库、Figma 基础变量和既有订单详情流程节点。
