# UI 信息架构收口决策（2026-08-12）

## 已确认决策

### 1. 发起返工页面

- “发起返工”仅承担填写一张新的返工单，不承担历史订单查询、切换或后续状态操作。
- 页面打开时直接展示空白表单；不再显示“我的返工单”、“新建返工”或个人历史订单列表。
- 正式提交只在服务端确认成功后清空当前表单、附件预览和本地提交状态，使操作者可以立即录入下一张单据；失败时保留当前填写内容。
- 保存草稿仍属于当前填写过程。离开发起页后，草稿与其他已存在订单均从“全部订单”查询进入订单详情。
- 提交后的撤回、取消以及撤回后草稿的修改和再次提交，统一在对应订单详情的 N01 节点处理。既有服务端状态机、权限校验、审计与接口不变。

### 2. 页面标题

- 一级页面统一使用同一左对齐、主标题字号、标题区间距和右侧状态/操作区。
- 标题只保留一行黑色主标题和一行紫色功能说明；不再使用主标题上方的眉题。
- 系统管理、工资管理及其他使用独立标题实现的页面，接入相同标题结构；不在卡片内部另起特殊主标题。

## 不在本次范围

- N08 责任结算、钉钉登录/待办、权限规则、订单状态机、服务端接口和数据迁移。
- 调色盘、组件库、Figma 基础变量和既有订单详情流程节点。
