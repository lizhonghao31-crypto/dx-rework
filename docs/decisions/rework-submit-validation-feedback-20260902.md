# 返工提交校验反馈规则

日期：2026-09-02

## 规则

业务条件不满足时，主提交按钮不能表现为“点击没反应”。

- 仅在请求处理中、上传中或缺少服务器对象等技术互斥状态下禁用按钮。
- 资料不完整、数量不合法、比例不等于 100%、倍率不足或未选供应商等业务条件，按钮保持可点击。
- 点击后同时：
  1. 在页面状态区写入具体原因；
  2. 打开统一站内提示弹窗；
  3. 不发送 API 请求。
- 提示必须说明具体字段和正确要求，不能只写“提交失败”。

## 本次覆盖

- 发起返工：款号、加工厂、订单跟单、整查承担方、报告图片。
- 历史整查/尾部数量：返件总数、各工序整数数量、单工序不得超过返件总数。
- 责任判定：处理人、整查承担方、责任比例合计、重复责任方、倍率和供应商。

其它节点按同一规则在后续独立 PR 覆盖。
