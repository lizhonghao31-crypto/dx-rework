# IE 调价复核信息降噪决定

状态：已确认  
日期：2026-09-02

## 业务规则

- N05 未调整某一工序单价时，N06 不显示该工序的原价、提议价或“沿用原价”提示。
- 只有实际调价的工序才显示原价与提议价。
- 实际调价工序提供“同意”和“驳回”两个文字操作：“同意”使用绿色文字，“驳回”使用红色文字；不使用边框、色块或额外图标。
- 多个工序调价时，IE 逐项作出选择后统一提交整单复核结果。
- 任一调价被驳回时，整单按现有状态机退回尾部主管；全部调价同意时，整单按现有状态机通过。
- 本决定只改变 N06 信息与操作表达，不改变价格、工资、审批状态、审计或后端接口口径。
