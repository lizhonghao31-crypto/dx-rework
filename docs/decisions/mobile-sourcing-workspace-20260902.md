# 外发定价与选厂移动端业务页面

日期：2026-09-02

## 结果

手机端不再显示“仅开放电脑端”的占位页。具备 `sourcing:view` 的账号进入外发模块后，直接使用真实的创建、待审批、历史和订单详情页面。

## 角色界面

| 角色 | 移动端可见内容 | 可执行操作 |
| --- | --- | --- |
| 订单跟单 | 创建订单、待审批、历史、订单详情 | 新建订单、多项工艺、上传照片；按节点申请转厂 |
| IE | 待审批、历史、订单详情 | 当前 IE 节点报价 |
| 生产管理 | 待审批、历史、订单详情 | 调价、选厂、转厂审核、财务差异核实 |
| 老板 | 待审批、历史、订单详情 | 最终批准/驳回；需要时审批转厂 |
| 加工厂应付会计 | 待审批、历史、订单详情 | 核对批准后的供应商、单价、数量、总额 |
| 其他仅查看账号 | 权限范围内的列表和详情 | 只读，不展示无权按钮 |
| Root | 全部外发页面 | 全部授权操作及删除入口 |

## 移动布局约束

- 以 390px 宽度为基准，不允许横向滚动。
- 表单、列表、流程、办理区采用单列；核心事实采用两列紧凑卡片。
- 所有办理按钮保留原 API、权限和状态机，不创建移动端旁路。
- 工艺录入保留多项清单，不降级为单个自由文本。
- 底部导航预留安全区，不遮挡提交按钮和最后一段内容。
