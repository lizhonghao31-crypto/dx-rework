# 我的待办未完成数量角标

状态：已确认  
确认日期：2026-09-02  
适用范围：共享“我的待办”导航入口

## 决策

- “我的待办”角标表达当前用户实际未完成事项总数，不表达已读或未读。
- 数量统计覆盖订单返工与外发定价&选厂两个模块，口径与统一待办列表一致。
- 点击入口、进入页面或停留在“我的待办”页面都不得清除或隐藏角标。
- 新增待办时数量增加；完成、取消或转交后，原接收人的数量减少；转交后的新接收人数量增加。
- 数量为零时隐藏；1 至 99 显示实际数字，超过 99 显示“99+”。
- 样式为 iOS 式图标右上角红色实心数字角标，不增加导航卡片高度，不显示额外提示文字。
- 桌面端和移动端使用同一业务口径及视觉语义。

## 技术约束

- 服务端未完成待办事实是唯一数据源。
- 删除浏览器本地已读水位线及“打开即确认”的行为。
- 保留现有定时刷新与页面重新可见时刷新机制。
- 不修改待办创建、完成、取消、转交状态机，不新增数据库迁移。
