# 9月11日四项优化验收清单

本轮按《9.11需求.docx》固定四个 PR 实施。验收使用测试人员与明确标记的测试订单；工资标记使用隔离工资明细。代码合并、部署和业务验收分别记录，不能相互替代。本轮浏览器环境阻止访问本地预览地址，未完成实际页面视觉验收。

## PR01 工资已结清

| 场景 | 预期结果 |
|---|---|
| 工资财务、财务总监、Root 进入工资管理 | 可使用“工资已结清”；普通工资查看账号没有该操作权限，直接提交也拒绝 |
| 工人/返工单/款号、正式工/临时工、起止日期交叉筛选 | 沿用输入即出；按实际报工完工日筛选，包含开始和结束两日 |
| 同一人多条明细、两个同名但不同编号的工人 | 人数按人员编号去重，同名不同人分别汇总 |
| 筛选超过 500 条明细，翻页后点击 | 确认人数和条数涵盖全部筛选范围，不限当前预览或当前页 |
| 确认后重试或再次点击 | 已标记明细不重复处理，原标记人/时间保留；分批中断可刷新后对剩余明细重试 |
| 确认快照之后新增明细 | 新明细仍未结算，不自动纳入本次标记 |
| 刷新、重新登录，查看历史锁定明细 | 标记持久有效，旧历史工资仍可读；旧月结不等同于已发放 |
| 标记前后核对 | 工资金额、归属月份、返工状态及扣款记录保持不变 |
| 页面外观 | 原快捷周期、汇总、工人汇总、明细结构保留；结清次按钮与最右蓝色导出按钮等高、底部对齐；未结算/已结算用原黄色/绿色状态样式 |

## PR02 待办搜索与返回

| 场景 | 预期结果 |
|---|---|
| 返工、外发、生产待办输入真实订单跟单姓名 | 命中当前账号原本可见的待办；总数与分页结果一致，原其他关键词搜索保留 |
| 样衣待办 | 保持原搜索，不添加不存在的跟单关系 |
| 从第 2 页或更后页进入任务，使用页面返回及浏览器返回 | 原搜索词、模块和页码保留，并重新查询最新待办 |
| 完成一条任务后返回 | 任务从待办消失；最后一页变空时回到最后有效页，搜索不清空 |
| 连续输入搜索词后浏览器返回 | 不出现每输入一个字产生一条历史的情况 |
| 切换账号 | 不复用上一账号的查询状态，仍按新账号权限查询 |

外发及生产的跟单姓名沿用当前系统已使用的外发跟单建单责任关系；返工使用订单独立的 merchandiser_user_id。

## PR03 质检与仓库

| 场景 | 预期结果 |
|---|---|
| 单独质检账号进入返工单看板 | 可见款号、返工号、加工厂、跟单、数量、原因、照片及当前进度 |
| 展开基础资料 | 无工序核价、工资、判责、审批明细及相应业务节点入口；接口只返回基础字段白名单 |
| 直接请求受限节点 | 工序、分工/报工、数量复核及责任节点读取仍拒绝，即使是质检本人发起的订单 |
| 原质检发起、本人资料处理 | 继续按原规则工作 |
| 质检兼有其他有效业务角色 | 保留原业务看板与权限，可切换查看全部返工基础信息；Root 保持原行为 |
| 仓库原收货页 | 左上“小按钮”直接进入现有订单回货，返回回到仓库收货；默认落点与收货字段/按钮不变 |
| 仓库操作权限 | 不因新增入口得到装箱修改、订单删除、返工发起或 Root 修正能力 |

## PR04 财务总监节点只读

| 场景 | 预期结果 |
|---|---|
| 查看发起、工序核价、预分工、分工及报工 | 显示已保存的真实资料、人员、数量、单价、版本及处理记录 |
| 查看尾部数量确认、IE 复核、数量调整 | 显示真实确认数、有效报数、修正记录、价格快照及审核意见 |
| 查看责任判定与老板签字 | 显示实际责任方、供应商、各责任方倍率、分摊金额和签字历史，包括已驳回历史 |
| 查看扣款及工资 | 显示真实扣款、结案、异常特批及工资明细；保留原合法财务操作 |
| 当前与历史已完成节点 | 都能读实际记录；未开始节点仍显示未开始，无记录时如实显示暂无已保存记录 |
| 附件 | 通过原附件鉴权预览/下载，不能以新能力改写附件 |
| 直接调用无权写入接口 | 工序保存/提交、调价、报数修改及审批仍受原角色与能力校验限制 |
| 多角色账号与 Root | 当前节点已有的合法操作工作区保留；Root 不变 |

## 自动验证范围与实际验收区分

本地完成合同构建、API/Web 类型检查、ESLint、Web 构建、迁移静态验证与全套测试。新增隔离 SQL 回归验证工资全范围和幂等、质检白名单与权限拒绝。完整业务链回归读取全部 12 个节点，核验读取前后订单版本、状态和工资不变，以及质检/财务越权拒绝。每个 PR 对最终提交执行仓库 Full Gate；Review 按每个 PR 最多一轮处理真实问题。

运行环境验收前需部署对应合并版本并正常应用 0171、0172、0173 迁移；本轮没有操作生产工资、生产订单或执行生产部署。
