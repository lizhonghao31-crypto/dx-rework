# P04 核料整页与分项全选

基线为 release/digital-production-v1@7abe0545f43fda60dbe8bf403e76259e0ac29424。本增量堆叠在 P03 修复日期夹具后的 0b969e368835d6bc697bd2a0a9df2a5b167d71f6；draft，不合并或部署，管理座舱 UI 不改。

## 用户结果

核料材料同页逐项显示，四项标题分别提供全选，显示整页已勾、可补选、排除数；范围包含滚动之外的材料。只补选本项已确认使用且适用的格，不改 usage、不用说明、其他三项或真实事实。空白模板不代表不用。材料旁显示排除原因，电脑四列、窄屏两列，长材料名与规格自然换行。正常提交与退回按钮明确，原结果下拉删除；退回仍需 P02 结构化材料、字段及原因。

沿用 0247 草稿与正式应用存储，无新 migration。保存只写草稿；正式核料才应用。保留原质量报告、决定、材料记录、使用确认及历史；低频任务管理收在核料办理中的详情，不改权限和操作。缺少新版材料确认读取时停止保存/提交，提示管理员核对 API/schema，不用旧 requiredThisRound=false 解释成文员不用。

## 同源资格与真实阻断

execution 的 materialVerification 读取增加每材料四项 bulkRules；资格来自结构化退回需求、同单同轮核配及到料/代用记录和质量报告。比较资料未登记只限制批量判断，不擅加发布必填项或把未知当成已知不符。自由备注不解析为错误字段。补正导致失效的四项不自动全选，先由文员重新核实保存。

保存的可选 bulkChecks 明确本次批量涉及的格，最多 400 且不得重复。服务端在原任务权限、当前轮、生命周期锁、资料版本、草稿版本、幂等事务中重新判断；批量不适用/质量已变化/known conflict 拒绝且不写入。即使手工勾选或省略 bulkChecks，也不能把未解决的已知缺料/不符抹为 true。原质量决定守卫仍在正式提交路径，Root 原有角色特权保留，不能用 Root 绕真实业务事实。

缺拉链/扁机仍只允许原纸样、裁板例外，不把缺实物勾成已到；车板仍按真实齐料和质量事实。已退回的四勾或其后到料不能当成“核配通过”，须真实文员复核。合法核配通过时记录的缺料例外仍按原到料规则解除，不新增审批。

## 保存、提交及导航

继续使用原 save→check 串行命令、同一未知写入重试键/请求体和 checkReceipt，不重造回执账本。明确区分保存中、草稿已保存、提交中、提交拒绝、结果未知、已写入但读回失败。未知期间锁定输入，核对原命令，不能悄悄换键再提交。

核料明确通过后自动进入同 source/round 总委派；退回、拒绝、未知及仅保存不导航。通过回执在后续读取前记录，因此读回失败不否定核料成功；导航失败只重新打开目标，不再发 check。WorkbenchAction 的 button 不再覆盖相邻 submit 的 form.id，两个明确动作仍正确绑定原表单，移至工作台页脚后显式保留 busy/unknown 禁用。

## 覆盖与确认边界

主覆盖 D01—D06、D09，B15 例外边界及 D07/D08 已确认补正/补料复核部分；D04 主验收在本 PR。总委派自身 P05、辅料库 P06、全站反馈 P10 及后续各域治理不混入。

D08 已由用户确认选 B：行政工作由文员承担，不给设计师增加申请或行政入口。已退回且仍在当前轮有效补正／补料中的事项，由原有权文员主动“接回文员重新核料”，记录与设计师沟通后的原因，在原核料页重新确认使用／不用。设计师不能改变文员用途；Root 保留既有特权，不增加主管常规审批。

接回使用原生命周期事务锁、当前资料／草稿版本、同人同命令幂等记录和任务机制。原补正／补料取消留痕，不记录虚假补料完成；同轮只保留一个活动核料／补料任务。重复或并发接回返回同一后继，跨单、跨轮、暂停／取消、已结束或过期快照拒绝。旧补料及补正写入在原状态守卫拒绝，不能覆盖新确认。旧正式资料、退回、草稿、到料、审计和质量记录保留；经既有规则确认的 pre-0248 补料也可由原文员接回，不制造无意义修订。

接回和保存用途都不放行。重新提交后才应用新用途；不用仍须记录确认设计师及说明。独立的资料缺错／已知不符会随接回保留，不能改为不用、改问题性质或清空问题而通过；文员须保留该问题退回原设计师补正／补料，再按原链复核。质量停用仍由原供应链总监／Root 明确处理，接回不豁免。成功重开回执验证任务与轮次后进入本轮核料，保留可再次打开的链接；网络丢回执、坏成功响应或408保留原命令与输入，核对沿用原正文／键，不自动新建。

## 测试与风险

本地全套、PostgreSQL、真实 React 组件浏览器及 FULL 结果按最终 HEAD 在 PR 记录，不以旧 HEAD 或跳过代替通过。浏览器是明确的合成 TEST 响应，实库服务回归另跑，不能称部署现场多角色端到端。

聚焦 1/7/100 材料，pending/use/unused、部分已勾、四项隔离、缺料/不符/质量、保存重开、无协议停止写入；正常/退回与结构化矛盾；保存后 check 拒绝、未知写重试同键同体、确认成功读回失败、导航重试不写；权限拒绝/版本冲突/并发/重复/事务回滚/原工资与历史兼容。工作台共享组件另回归 21 情境两宽度。

部署现场、真实 125% 缩放、移动键盘/触摸未验；D08 实库与合成组件浏览器结果单列，不等于现场验收。无迁移/批量回填；回退只撤交互，保留 0247、P02/P03 及正式事实，不删除历史。若批量资格不可确认，停该批量动作并保留合法单项办理；不通过关掉服务端守卫恢复可用。
