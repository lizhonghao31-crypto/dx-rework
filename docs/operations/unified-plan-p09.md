# P09 座舱目录的业务存在性与读取状态

本增量只处理 A01 功能部分；管理座舱布局、字号、对齐、分区、流程图、PO 表、壳和全部 CSS 保持原样。不是被否决座舱视觉稿的实现。不新增业务 API、权限、数据写入、迁移或跨域存在性查询。

## 来源与生命周期

继续使用 cockpit-documents-model 的十一类原授权目录来源。进入当前单后最多并发三个原 GET，同路径共享响应；样衣/杂事共用分页元数据，订购与制单共用当前制单响应。只预读目录；历史版本、实际原件仍按打开条目读取，附件字节不会自动下载。没有把 P07 的目录预读计为阅读或完成事项。

当前快照只属于已经核验的本人、订单/来源、所选轮次、资料版本、资料时点及授权关联。展开路径不作为失效键。切单、换轮或会话失效立即卸载旧目录，取消其 GET 和排队读取，迟到响应不覆盖新内容；所选对象尚未到达时不拿上一单预读。旧响应未带 asOf 时使用当前 order 对象的稳定修订号，不用渲染时间制造无限加载。

idle/loading/error 与 created/missing/not_applicable/unknown 分开。尚未读取、读取中、读取失败、无权读取都不是业务尚未创建；已创建仍保留草稿/发布/历史版本原事实，不把开发草稿作为生产前置。无授权合同或裁床关联仍无法确认，不全域扫描补关联。403、含糊 404 不披露名称、条数和存在性。其余类继续正常读取。

关联目录每次最多读取三页，合并真实条目 ID；没有匹配 kind 且仍有后页时为无法确认，提供继续读取。找到匹配项即可确认已创建，但后页仍如实提示。异常或倒退分页不当作无记录。明确无记录且排尽才显示尚未创建。重试只针对失败目录；错误响应、无效结构和错误版本不留作成功缓存。服务失败续读保留本快照已验证前页，权限拒绝不保留隐藏数据。

现有资料响应携带身份字段的来源/母单/预算/制单/产前/工艺/收尾按原字段核对本单，不能把别单回包当成本单目录。历史版本原有轮次和版本核对保留，不能用最新版冒充旧版。现有目录元数据可能含当前 document，本增量不再主动展开其版本或下载文件。

## 证据与限制

目录定向单测 19 项，另回归原座舱 16 项：保留原九项历史/草稿/原件/权限测试，新增十项快照测试，包含十一类来源、最大三请求、共享响应、按需原件、三页预算/继续、循环分页、403/404/503、坏成功响应恢复、错实体、历史版本回退拒绝、身份/迟到回包及输入快照不可变。实际目录 React、auth 生命周期的六组浏览器场景另验证展开前已有结论、开合缓存、分页续读、拒绝隐私、定向重试、切单/换轮、换账号及全程 GET。

浏览器采用合成 TEST HTTP 元数据，原 P08 组件经独立 alias 编译作对照，断言其没有新 data-read-state 属性，避免误把当前组件当旧版。相同资料读毕收起后比较原 details/summary/strong/span 结构、类名及 summary 的高度、字体、行高、padding、display、gap；未修改任何 CSS。原件链接只生成，未下载文件。此证据不是 ECS、真实订单或现场人工验收。

早期单测缺失原 execution GET 夹具造成一次失败，补齐夹具后重跑；原座舱 SSR 测试仍期望旧“待判断”，改为明确断言初始“尚未读取”且不含旧文案，其余结构/权限断言保留。未放宽业务判断。最初浏览器对照 alias 未命中，结果只算初轮；修正 alias 并断言原组件后六组重跑通过。更早全应用布局脚本的并行选择断言在基线也失败，仍不算本 PR 已通过，不以视觉改造绕过本轮排除边界。

最终 HEAD 常规检查、FULL 与唯一 Review 在 PR 中记录。D08 用途异议仍待决定，没有被本目录读取解决。

## 交付和恢复

依赖当前原目录契约与 P08 真实关联，不依赖任何新阅读写协议。无迁移、业务回填或订单恢复步骤。撤销本前端增量可恢复原目录按需读取，不删除资料或阅读记录。所有 PR 保持 draft、未合并，部署及第一组合并另待放行。
