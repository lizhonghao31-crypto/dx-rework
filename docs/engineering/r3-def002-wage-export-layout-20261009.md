# R3 DEF002：工资导出列宽

依据第二阶段报告 `R3-stage2-report.md`（Library `libfile_924498ea575c8191928ef76431e25dbb`，版本 1）。

工资明细、人员汇总及报表中心的工资导出按实际标题与内容设置列宽，中文按显示宽度计入，长标识和时间可直接阅读。列宽上限 72，超长文本换行；金额、数量、高精度数值仍用原数字格式，长编号仍为文本。

只改变 XLSX 展示，不改变字段、顺序、金额、导出授权、工资释放时间或数据快照。其他报表保持原布局。回归解包真实 XLSX 核中文标题、SHA、长编号、超长文字及数字格式；既有导出权限与计薪测试保留。

无迁移、部署或实际业务数据变更。最终视觉复验需要用户部署后由浏览器验收主体重新导出查看。
