# C2 版单字段、出入板事实和独立客户评语单

施工依据为 2026-11-25 v11.5《复版双单大图打印版》§4.1–4.7、§8.4/8.6、G2/G3。按开工时远端发布基线 `99e3451bb057e44a7079aaee52c8673b45e9cb16` 对照，#1097 `5865c812` 是祖先，其凭证开始、完成两处生命周期保护仍在。此处只说明 C2 取值和权限，不表示部署或现场验收。

| 表单和印件 | 原值或者事件 | 边界 |
|---|---|---|
| 衣类、尺寸项目、各尺码、尺寸单位、顺序 | `DevelopmentDocumentSchema` 的 `template/sizes/measurements/unit`，首次可用 `DEVELOPMENT_MEASUREMENTS` 对应默认表 | 新建明确选衣类，尺寸始终选填。草稿保有意清空和两类已填尺寸；发布只冻结当前表。历史无可信衣类不猜，实际行列照印。不使用正式 PO 或技术独立尺寸表覆盖原版单。 |
| 版型、原打板类型 | 已保存的 `workbenchSheet.boardType`、源单原 `developmentType`。参考款及版型文本保原位置 | 不增加第二个版型、初版/复版/齐色版字段，不读取执行单年度默认 variant 当成资料版序。 |
| 订单ID、款号、客户、设计师、数量、尺码 | 授权的源单、既有编号绑定、精确资料版和 `developmentMakingSizes` | 分列 ID 与款号，不以代用号、客户 PO 或最新表补。独立复版另印实际复版序号、本地轮次、原开发轮，有原母单读取权限才附母单号。 |
| 预计、发板、回版 | `returnDate` 为预计；`development-print-details.ts` 从真实原生提交或返工事件及待派工节点读取本轮发板，读同轮设计确认的可信发生时间或单轮原确认事件 | 缺失、历史批量补交接、继承他轮、工艺布片或日期未核实不猜填。展示回版不改写工期、实际、原工资或任务。资料补正可以保本轮事实，但有依据时标明发板所据旧资料版。 |
| 原款图、制作数量、制作要求、面辅料 | `development-print.tsx` 从指定版 `files`、`sizeQuantities`、原朴料/车缝、洗水、包装、尺码标识及唛类、`materials` 读取 | 已授权精确附件用对应版本接口。动态尺寸或多材料自然续页，不重新输入。印件不放内部成本/报价。 |
| 独立《客户评语单》 | 老记录只用该次实际复版保存的原文，由精确版单 API 提供；复用组件接受已授权的 exact commentRef 对应文本、版本和原图 | 无可靠附件关联不猜，内部无评语只印版单。C5 负责新评语绑定、原图成员核权和新复版发布。客户原话只出现在独立单据，每单单独起页、独立计页，一次打印。 |
| 打印入口与异常 | 当前版 GET 和精确历史 GET 经现有权限后读同一投影，补正历史选择也重读 exact 版本；预览框先解码图片、备字体并分页 | 旧页保留。读失败或图片损坏明确错误，不偷用最近版本、不打印少图的假成功。不因打印新增发布、工序、时效或其他写入。 |

局部浏览器合成用例和数据回归可先验 C2，按原顺序合并。C5/G3 原意见驱动复版、当前表直接发布、原审批和跨入口防重，以及真实原图权限联合验收不是 C2 的仿真结果。

C5 联验用同轮已采纳评语 A 与后写评语 B 各自不同的原图。普通板房角色沿用既有业务授权打印时，独立评语单应读出 A 的原图，即使该图不是版单附件，也不能混入 B 的图。以真实角色和两个明确的附件身份分别断言，C2 不依赖此联验。
