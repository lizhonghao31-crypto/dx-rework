## 实现与验证

- 两个入口共用本模块输入处理：普通编辑、粘贴、输入法确认均检查；混合文字整次拒绝并恢复原值/选区，合法千分位粘贴验证分组后转换。组合内容与业务价格分离，组合期间禁止提交。
- 空值/尾随小数点可编辑但不能提交；沿用现有新报价 schema、有效精度和金额算法，不截断或猜测价格。错误只在对应价格框短提示，不增加常驻提示或弹窗。
- 前后端按 position 对照并精确比较。所有行低于/等于 IE 可不填说明，任一行高于仍必填，不用订单总额抵消；自愿说明与中性默认说明保留，降价仍显示为调价。
- 单元测试执行生产输入事件处理器，覆盖整段粘贴、分组选区、输入前拦截/输入后恢复、删除与小数中间态、组合输入、错误清除及千分位聚焦/失焦。不把处理器测试描述为真实浏览器事件验收。
- 服务集成覆盖低价/同价留空、自愿说明、混合涨降价未填或空白拒绝、行不匹配、非法字符/零/负价拒绝、填写后进入老板审批。接口测试另覆盖超精度/尾随小数点拒绝。
- 本地隔离 SQL 定向回归通过；完整业务链由当前 PR 的 Full Gate 在 PostgreSQL 16 验证。本地精简检出缺部分历史文档，完整仓库 Gate 是最终门禁证据。
- 实际普通浏览器、移动端及钉钉客户端输入法/光标/视觉验收尚未完成，需部署后人工验收；不以事件处理器测试、构建或 CI 全绿替代。
