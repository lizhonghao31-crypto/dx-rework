## 已实现与集中自查

路由只观察原生 replaceState 成功后的完整 href/state，不触发同页 sync/remount；卸载恢复原 History 方法。文档一直保留原来源路由，内容 kind/id/version 只取授权目录；不适用类别不产生实体。选中预算/制单的版本作为展示参数保存，原来源、筛选、returnTo 不重建，合法版本检查仍拒绝重复、非法数字、外站与循环返回。

生产资料读取按当前权限指纹、会话版本、原订单/工厂版本标记；未知提交则按原主体 ID 和原业务目标保留内存快照。**同账号换岗不能抛弃原未知提交并另发一笔**，也不能让旧权限的读取继续显示。离开再返回仍发送同原文/幂等键，发送中保持锁定；原请求成功后通知当前页面清除恢复状态，旧恢复控件不能另配新键。没有持久化输入或凭证，没有自动重试，没有改变原 23 小时安全重试窗口或服务端授权/幂等。Root 范围维护沿同样的主体分区和迟到反馈保护，未修改角色/人员或范围写入契约。

N05 当前/未来节点缺少明确受派人时显示“未记录具体负责人”；完成节点只从原授权 `rework.tail_completion.confirm` 审计事实取最近已办理人，同刻人员有歧义仍未知。此处 MAX 用于**审计记录顺序**，不作为业务起点/截止。时间候选索引更新为 411 文件 / 1629 处，只新增此审计候选和原日期控件行号，没有将索引匹配当作全局语义验收。
