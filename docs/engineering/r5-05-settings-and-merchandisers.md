实际集成起点：`be61c84d0e05cbc9428c974fdfbe1b00aff4ad89`（R5-04 #964 已合并）。本项对应完整 v2 与修订九 PR 表的 R5-05，以及用户后来批准的客户批量主／多副跟单。授权包括源码、独立 Codex Review、必要 Full 和顺序合并；不包括部署、现场数据或真人赋权。

## 已实现边界

- 一份节点用时、日历、提醒；原事件、内含、预计、约定日期、提前提醒和监督周期保持各自含义。洗水不再用另一输入覆盖新标准。只在明确导入旧标准时转换，既有订单的冻结副本不重写。
- 设置常驻阶段／整单跨度，沿当前选择的实际路线调用 R5-04 同一正反向图与日历。阶段可跨阶段并行，阶段跨度不能简单加成整单。未知保留未知，不把提醒、监督周期、内含交接、可选返工再加入主工期。
- 右侧编辑即时演算；确定／取消、整页放弃、同单刷新与真实未保存离开保护区分。单按钮保存并使用，冲突保留手工修改并与新基线核对；未知回执保留原动作、内容、键，已成功但刷新失败不伪称保存失败。
- 历史统一包含新完整标准、旧真实配对、旧单侧时效及未配对开发周期。先统计／分页，再读取本页内容。部分记录标明不完整及具体缺项，缺的部分不借用今天的值，也不能直接启用或作为完整历史导入。可完整还原的历史使用这版直接追加新公司版本；删除只隐藏历史入口，原定义和订单冻结依据不删除。
- 演算与设置同组织，独立临时输入、一组条件、多个 PO、重新填写／导入历史，取消过时的自有只读请求，不取消业务提交。客户日截止仍是排他的次日边界，显示“前”，不把边界午夜误称可包含的时刻。
- 客户列表完整搜索／计数后显示当前 15 条；跨页选择保留。每客户一名必填主跟单，副跟单选填、可多人、去重。批量明确追加或替换；保存复核所选客户版本及全部保留人员资格，整个批次原子提交。原客户数组和其他业务选择器保留。
- 默认设置只复制到新订单；已有订单不覆盖。数字外发从新单继承全部副跟单，兼容旧单副跟单字段。全部副跟单沿原权限读取／回传合同、接收对应待办；不取得主跟单编辑权。当前主跟单不重复收同一副跟单通知。首次回签时刻不因后续添加文件变化。
- 新增关系变更沿原 OLD/NEW 同事务登记更新；座舱／期间统计读取完整人员关系，权限、全局计数、排序、15 条富化及原 PERF01–12 不变。

## 分批启用

`ORDER_TIME_MODEL_ENABLED` 当前为 false。新公司标准发布与正式新采用链在 R5-07 一同启用，不能让旧采用器吞掉新的日历、提醒和分工艺字段。R5-05 已安装的读写模块不提前改变订单采用；既有旧接口、冻结和 UI 兼容路径继续运行。客户默认跟单可在本项同一版本完整接线后使用，不依赖时效切换。测试服务器明确启用新设置仅验证将来组合，不能冒称现场已经启用。
