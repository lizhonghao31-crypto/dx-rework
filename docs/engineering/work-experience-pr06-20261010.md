# PR06：制单正文保存与开发来源核对

保存制单只更新正文草稿，保留已采用开发轮次。开发换版后，只改备注或自动保存不再消除未核对提示。首次保存开发来源制单还校验客户端看到的初始轮次，避免来源已换版时把旧正文误标为新轮次。

编辑跟单可查看发生变化的开发技术组：工艺、说明、尺码与尺寸、附图、面辅料及成分。界面对照原开发、本单当前填写、新开发；展开核对后逐组明确选择采用新值或保留本单原值。确认核对同时保存正文和采用记录，检查制单版本、母单版本、开发轮次及开发文档版本。采用只影响所选组；保留保有自定义大货差异，附图采用追加新图而不删除原图；尺寸采用保留本单公差、量法和人工新增部位，新尺码缺值仍须补齐后发布，未变化组及其它正文不重新初始化。

核对复用原事务、权限、生命周期、开裁冻结和幂等命令锁，标准审计记录原轮次、目标轮次、文档版本与逐组决定；制单显示核对人、时间、版本及保留/采用结果。发布继续校验最新开发采用关系、母单版本、必需技术内容并使用原产前链路。旧发布版本正文、版本源、图片和打印快照不变；补正式 PO 和客户日期申请继续原入口。没有迁移，没有财务放行条件，没有 ECS 或真实数据操作。
