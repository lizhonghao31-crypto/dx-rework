# PR-05 Preflight：全业务页面信息噪音专项治理

- 基线：`main@056263194ee104dbf6bd3f38e71effdf64acdf0b`
- 分支：`feat/v1-business-information-noise`
- 数据迁移：无

## 信息唯一性规则

1. 节点名称和当前状态在订单详情只保留一个主展示。
2. 独立业务页面继续保留 Hero、标题、节点说明；嵌入订单详情时隐藏这些重复上下文。
3. 人数和数量仅在影响选择、提交或核对时显示。
4. 已完成节点的处理历史默认收起，由用户按需展开。

## 施工范围

- 工序配置、历史工序配置、执行报数、整单复核、责任判定和供应商扣款增加 `embedded` 显示模式。
- 订单详情统一使用嵌入模式，不再重复节点号、节点状态和独立页说明。
- 办理区只保留通用标题；节点主信息仍由订单流程和对应业务内容承担。
- 系统管理、审计日志和技术异常页不在本次治理范围。
