# 供应商中心验收说明

本轮口径以 [已确认需求](../requirements/supplier-onboarding-20260912.md) 为准。

| 身份 | 资料维护 | 新增申请 | 审批 |
| --- | --- | --- | --- |
| Root、老板、生产管理 | 直接新增、修改、启停、批量录入 | 使用直接维护 | 可以 |
| 订单跟单、印绣花/洗水跟单 | 申请新增供应商、我的申请 | 仅本人申请 | 不可以 |
| 其他已有供应商查看身份 | 查看目录 | 不可以 | 不可以 |

兼有老板/生产与跟单角色时优先直接维护；普通角色仍须具有对应 capability。

## 建议验收步骤

1. 老板、生产进入“供应商中心 → 资料维护”，直接新增、修改或批量录入。只读账号不出现维护入口。
2. 两类跟单分别进入资料维护，提交一份完整申请。收款账号以 `00` 开头时完整保留；其他跟单看不到该申请。
3. 老板或生产从“待审批申请”或“我的待办 → 供应商中心”打开详情，核对完整资料和查重结果（正式资料含停用、其他待审批申请），可刷新查重；发现重复时不能通过。退回时必须填写原因。
4. 原申请人查看原因，修改后重新提交。新旧版本均可查看，各版显示各自的名称、提交时间和审批状态，旧版本没有操作按钮；新的审批待办取代旧任务。
5. 任一审批人通过后，正式目录仅新增一条供应商，申请变为“已通过”，同伴待办关闭。另一审批人停留在旧页面操作时应提示状态已变化。
6. 用同名称、同类型再次提交或直接新增，应提示重复；已有停用资料也参与防重。申请待审批期间不进入正式选厂列表。

## 验证边界

自动化覆盖角色允许/拒绝、本人范围、敏感字段、版本状态、幂等、重复名称、并发和事务回滚；Gate 与独立 Review 结果以对应 PR 的当前 Head 为准。

当前工作浏览器访问本地预览被 `ERR_BLOCKED_BY_CLIENT` 阻止，未完成真实浏览器视觉验收。组件渲染、字段映射、类型检查和构建不替代业务验收环境中的实际页面检查。移动端重点检查单列、16px 输入字号、长名称/账号换行和底部按钮。
