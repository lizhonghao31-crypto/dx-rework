# G1 大货卡片边界与信息层级（2026-10-18）

本次只修大货纸样与唛架看板的卡片越界和已批准的信息精简。基于已部署 G1 `3a5605cc65b3e39e8b281bb79feeed0a1598ea1b`，目标分支 `release/digital-production-v1`。用户已批准在同一局部 PR 中完成两项修复；本次不包含合并、部署或 Acceptance 数据操作。

## 原因与修复

原四栏每栏最小 220px，扣除边框和内边距只剩 208px；内层却使用 `repeat(auto-fit,minmax(240px,1fr))`，把卡片撑到 240px。正常看板横向滚动不能解决卡片侵入相邻栏的问题。只调整大货宿主内层为 `minmax(0,1fr)`，保留原四栏和横向滚动，卡片及长文本在本栏内换行，不通过裁剪隐藏溢出。

`BulkPatternCard` 是本宿主的只读呈现组件。继续使用原 `PatternBoardLane`、`StatusBadge`、业务状态标签和期限计算；不修改共享卡片、Shell、token、开发看板、API 或任何业务判断。原筛选、scope 权限、15 条分页、数量、`bulkPatternLane` 分栏及 task/bulk/returnTo 路径保持不变。
