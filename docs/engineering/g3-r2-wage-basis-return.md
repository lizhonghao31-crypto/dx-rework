# G3 R2 工资依据与完成历史返回

范围为已授权的只读计薪依据呈现及来源返回，不修改工资生成、分配、舍入、月结或状态机，也不重算历史金额。

统一工资报表原先只投影数量和基础单价；已存在的工资读取／导出会读取尾部确认中的临时工系数、组总额和个人高精度份额。本次统一报表补充这些已有事实，系数选取限定在工资创建时刻以前的完成确认，避免拿后续确认倒灌历史；无法关联时显示历史未记录。单价及份额按存储小数完整呈现，工资金额仍使用原已保存金额。

合成回归包含 1001 件 × 0.01 元 × 1.2、个人份额 12.012 元及已保存工资 12.01 元，以及相邻 1000 件正式工、集体份额和板房／杂事依据。此示例说明已确认的代码缺项，不构成对现场 TEST-R3-TEMP-1008 那条记录的直接归因；本轮没有读取在线业务数据。

完成任务自动进入最后历史节点时，历史页此前丢失工资来源入口，并仍显示会回到相同历史节点的“返回当前节点”。本次保留经原工资筛选解析器验证的来源，包括日期、搜索及两个分页位置；本厂做尾已完成时不再提供这个自循环动作。QC 完成页保留可达的业务完成资料入口，未完成订单仍可返回当前节点。历史响应增加只读当前状态以决定导航文案，历史字段仍取原提交快照。

本地定向单元回归与全新隔离 TEST PostgreSQL 的当前业务链回归分别验证显示、来源路径、既有财务读取允许／拒绝及读取前后工资事实不变。具体通过数、最终 Head、Full Gate 与必要 Review 以交付证据为准。不得将模拟数据、源码推论或测试通过解释为现场业务验收通过。父窗口最终核验后才能合并，用户部署。
