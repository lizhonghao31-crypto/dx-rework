## 完成标准

1. 三个二级入口：订单打板/杂事看板、创建订单、价格管控。
2. 每张单独立卡片；标题、信息及空白主区域均为同一链接。垃圾桶不嵌套在链接内。
3. 价格表整行边线一致；按钮布局不修改 td 的桌面 display。
4. 当前节点与历史节点分开，历史轮次不出现当前操作；提交后回到更新后的当前节点。
5. 正常完成、取消终止和转入返工分别呈现；历史执行段和金额保留 API 原值及权限裁剪。
6. 覆盖分配、工时、完工、交接/确认、返工、换人、取消、取消费用、资料和历史回看。
7. 真实视觉目标尺寸：1440×1024、1280×800、768×1024、390×844、360×800。截图对照必须使用本轮实际版本，不能用旧版本或静态源码验证替代。
