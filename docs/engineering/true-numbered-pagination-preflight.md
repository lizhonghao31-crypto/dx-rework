# 全系统真实数字分页收口预检

- 基线：`main@8105bc884c03244600fa98d06cb3ddd7c13d5c9c`
- 分支：`fix/true-numbered-pagination`
- 范围：全系统 14 类独立业务主列表统一使用 `ListPagination`；将仍使用游标的订单回货、返工单看板、外发订单、公共工序、审计日志、附件管理改为真实数字分页。
- 金标准：每页 15 条；第一页与最后一页常驻；当前页前后各最多 2 页；断层显示省略号；所有数字页码可直接点击；筛选变化返回第一页。
- 不在范围：缓存、预加载、索引、数据库迁移、业务状态机、权限、金额数量逻辑、部署与 Actions。
- 回滚：回退本 PR；不产生数据写入或迁移。

## 验收条件

1. 14 类主列表均引用唯一共享分页视图。
2. `CursorListPagination` 在产品代码中引用为 0。
3. 六个旧游标接口返回 `page`、`pageSize`、`totalCount`、`totalPages`，并支持直接请求指定页。
4. 桌面端与移动端沿用“我的待办”分页 CSS，不新增视觉组件或调色盘。
5. Full Gate 通过后再验收，不在本 PR 处理换页性能。
