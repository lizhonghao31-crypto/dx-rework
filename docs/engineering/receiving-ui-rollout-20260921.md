## 原页面清点及实现

订单回货实际由回货列表、仓库收货表单及办理弹窗组成，没有外发/返工式的审批节点详情路由，不新增虚构节点。

| 入口 | 保留的原业务信息和能力 | 本次 UI 修改 |
| --- | --- | --- |
| 仓库收货 / 补录 | 款号搜索、关联裁床、送货单数、实收、次品、图片、补录日期 | 紧凑标题与双列数量、左返回右提交、反馈留在表单内 |
| 多次收货 | 嘉顺/其他工厂来源、订单选择、来源对应数量字段 | 同一排版，保留来源分支和搜索结果完整说明 |
| 装箱录入 | 累计装箱数、旧版本留存与现有校验 | 原生模态焦点管理、等宽操作、错误留在弹窗 |
| 收货/装箱差异 | 原数量快照、处理结果与附件、处理人及时间、已有结果只读 | 紧凑事实栏、手机输入布局、等宽操作 |
| Root 单次修正 / 订单修改 | 原款号/来源/数量字段及条件图片替换 | 弹窗布局与关闭保护，权限条件不变 |
| 删除确认 | 尚未发起返工限制、原审计保留、取消/确认 | 等宽按钮、提交中禁止关闭 |
| 附件预览 | 上一张/下一张/下载原图/现有 ImageViewer | 同属原生模态层，保证差异弹窗上可打开凭证 |

列表、指标、筛选、分页、原多次收货历史与差异处理记录逐字保留。不会以当下汇总数字假冒过去提交数据。无接口/计算/权限变化。复用原输入、按钮与 ImageViewer；ReceivingDialog 仅服务这几个回货弹窗，不是组件库专项。
