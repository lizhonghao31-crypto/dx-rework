文员在现有核料页确认实际材料本轮“使用/不使用”；未确认默认待确认，不把设计师历史 requiredThisRound=false 或 true 当文员确认。选择不使用必须记录与哪位设计师确认和说明；本轮仍不能无主布通过。空白模板槽只标占位，不能冒充已经确认不用。设计师编辑器不再替文员选择使用状态。
