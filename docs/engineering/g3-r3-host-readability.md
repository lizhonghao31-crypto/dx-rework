# G3 R3 原宿主可读性修复

本包只处理供应商长名称、生产管理驾驶舱阶段标题及重复入口、既有异常报表的文案和记录链接。保留原业务字段、记录版本、状态、操作处理函数及权限边界。

供应商目录的 200 字长名称默认单行省略，通过原生展开、悬停及键盘读取全名。已有权限内的合同主体、银行账号同样可展开全文；受限账号仍收不到该信息。维护表单保持原结构。

驾驶舱阶段标题维持至少 13px 并允许完整换行；同一宿主内按原路径、版本、明细和办理方式去掉真正重复入口，不合并不同版本或查看／办理。节点表保留全部列，用有焦点框的可滚动区域承载完整内容，“查看／办理”列固定在右侧；选择记录及展开后的原记录均支持键盘。

异常报表沿用原查询和授权，只将已识别的异常／待办类别投影为业务文案；未知类别明确待核实。记录链接限定原有本地返工及责任页面，增加下划线与键盘焦点框。链接不授予权限，目标页面及 API 继续执行原有允许／拒绝检查。

隔离浏览器已覆盖 1440、1180、390 宽的目录、维护、受限账号、驾驶舱和异常报表；补测覆盖节点命令默认可见、键盘滚动、选择记录、异常链接焦点。不将合成数据截图视为线上或真人验收；最终组合检查、Head 和远端 Gate 状态见交付记录。
