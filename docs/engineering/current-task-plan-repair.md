## Read contract and consumers

`DigitalTask.plannedTargets` retains its original Fixed B meaning, values and
missing/pending forms. `dueAt` and native completion retain their R-based D/A.
`currentPlanTargets` is an independent optional read contract: exact canonical
work, scope/line, immutable effective plan ID/revision, target start/end and
date/instant precision, with explicit unknown/not-applicable reasons.

`arrangedOrderTimeTarget` is the existing Journey arranged-target selection
extracted into the minimal framework target module; both readers use it.
The extracted task-kind aliases preserve the prior Journey mapping unchanged.
The native read never calls Journey, reschedules a work, adopts a standard,
creates a route/plan or returns another task's facts. It runs after original
authorization on the original read client. PO labels are fetched in one bounded
query for only the selected scopes, not once for each work or PO.

The original fixed-target read supplies its captured position binding without
changing B. The binding validates adoption, route, round, kind, step and phase.
For older framework tasks without a position, an actual publication-root/round
route and a unique eligible native instance must also prove the relationship;
a same-kind/latest task alone is insufficient. Missing steps and ambiguous or
foreign identities remain unknown.

For a source task, a linked mother's effective plan supplies P only when it
contains this exact captured work. A mother may still legitimately adopt round1
while a new source round2 has its own current arrangement. In that case the
reader can use the source's current exact work; it never searches historical
plans or chooses whichever date is non-null. Completed old work retained by the
mother remains distinct from the new source work. A source with no mother uses
only its own current plan. Scenario/observation mismatch, deleted/ambiguous
mother and missing/foreign PO scope retain conservative results.

The existing task sample workbench, bulk workbench and task-detail panel render
this separate current-plan block. The existing R-based header is explicitly
labelled `自身截止`; it is not relabelled into a P. The new block handles per-PO
targets, date precision, missing basis and not-applicable without substituting
D, completion A or a PO average. Root's original P area still needs its own
field/route comparison before declaring that original sample closed.
