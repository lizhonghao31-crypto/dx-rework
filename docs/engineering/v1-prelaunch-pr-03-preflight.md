## 施工范围

1. 工序管理统一将“固定人员名单”改为“默认候选人”，并明确“新订单选择该工序时自动带入，可在订单内调整”。
2. N02 选择公共工序时只读取全局默认候选人，过滤不具备返工资格的人员后带入当前订单，并显示带入人数。
3. N02 在当前订单内增删人员不调用全局默认候选人写接口。
4. 新增一线入口页：仓管显示“仓库收货 / 我的待办”，工人显示“本人返工任务 / 我的待办”，尾查显示“本人尾查任务 / 我的待办”。
5. 尾查入口接入现有统一 N04 工作台与既有尾查能力，不新增 standalone 尾查节点。
6. N04 节点队列接受 `tail_inspection:report`，并按当前尾查人员账号过滤，只返回本人仍在执行的任务订单。
