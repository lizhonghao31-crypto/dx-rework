## 参考图与实现对应

| 区域 | 公共组件／页面实现 | 桌面与手机验收点 |
| --- | --- | --- |
| 关键事实 | KeyFacts；详情与列表共用 | 加工厂首位；详情数量、生产总额、IE 总额、差额、交期；不再每项一张大阴影卡片 |
| 审批摘要 | DecisionSummary | 单份业务摘要，工艺与裁床信息保留；当前老板节点显示审批提示 |
| 款式明细 | ResponsiveFactsTable | 桌面语义表格；手机有标签的独立款式卡片；权威数量和总额；预算字段裁剪对两端同时生效 |
| 图片 | ImageStrip | 小缩略图横滑、原有大图查看和补图；不抢首屏，不删除照片 |
| 流程 | WorkflowRail | 一份节点 DOM，细线步骤；手机折叠展开；历史可进入，未来不可进入 |
| 补充资料 | Disclosure | 完整资料与转厂辅助区在主要内容之后；待处理转厂自动展开，原节点处理入口保留 |
| 操作栏 | ActionBar | 创建页草稿／提交复用；老板拒绝在左、批准在右；手机避开 72px 主导航与安全区 |
| 其他岗位 | sourcing-node-workspace | IE／生产管理仍保留原编辑器及 UX-01 反馈，财务、差异处理与合同仍保留业务控件 |
| 外发入口 | governed 作用域 | 创建、待审批列表、历史列表与详情共同启用；不是只有老板页能看到新 UI |

图中的订单、金额、图片仅为示例，不复制到业务数据。打印、分享、历史版本按钮没有对应需求授权，本轮不增加。手机版保留系统现有主导航，所以操作栏位于主导航上方。长名称、多款等实际数据允许换行，不能为追求固定截图截断事实。
