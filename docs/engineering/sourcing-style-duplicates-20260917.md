## 口径

- 同单同款同色（正式号/代用号交叉命中）阻止提交；同款不同颜色允许。
- 忽略首尾空格和英文字母大小写；保留号码原始书写，不去连字符或前导零，不猜测错字。
- 跨订单当前及历史号码命中时，保存返回中文提示；用户明确核对为追加或分批外发后才能继续，并记录被确认的重号。
- 编辑只对新引入的号码做跨单提示，排除本订单；不反复警告未修改的已确认号码。
- 不向提示泄漏其他订单的数量、价格、工厂或人员信息。
- API 使用按号码排序的事务锁覆盖同时创建/改号；数据库新增触发器阻止同单重复行，历史数据不回写。
