## 实现

已完成节点链接不再滚动到 node-workspace 的摘要框，而是打开独立只读页面。旧 node 链接也进入该页；默认显示节点最新提交版本，可以选择其他提交版本。页面保留核心信息、双端图片／流程、逐款明细、该节点的完整只读业务字段及结果，明确回看人／时间和返回当前节点入口。

新增 GET /sourcing/cases/:id/history/:node，沿用现有读取权限及 mapCase 的预算价字段裁剪。节点版本必须属于指定订单及节点；无记录返回 404。使用原始行事实、截至提交时间的款号修订、独立报价／决定／老板及财务记录还原；老板及财务按自身关联的决定读取。时间截点在数据库内以原精度传递，不把 JavaScript 毫秒截断用作查询上限。图片按创建／补图审计中的当时清单筛选，缺失清单明确提示，不伪装成当前图片。

历史页没有表单提交回调、上传、修改、转厂、派单或审批入口，仅支持阅读、版本导航及图片查看。当前订单继续保留原业务写入处理，转厂按照原有角色能力在当前页进入与审核，不再依赖进入旧节点。
