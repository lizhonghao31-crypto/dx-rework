# 任务读取范围校正

任务详情、历史和工作区任务集合采用相同的精确任务读取权限。本人任务仍要求对应有效岗位，既有管理角色、原来源设计师、本人主跟单及合法协作角色按原范围读取。任务执行条件保持。

本人工作所需的订单制单、款图和业务前置事实继续由原资料读取权限提供。产前准备与裁后工作区保留这些资料及业务状态，只装载可读任务；人员预派字段不向普通任务办理人返回其他任务主办身份。

依据 `docs/requirements/pattern-room-finance-v1.0.md` 第8.3节：当前工人读取本人任务及必要制作资料；不同身份的有效角色按原规则合并，不因界面入口获得额外范围。没有迁移或员工、订单、真实角色变更。

验证覆盖本人读取和历史、同单其他任务拒绝、有效岗位撤销、混合角色、管理与源单协作范围、本人工作区完整读取。PostgreSQL业务回归沿原前置、派交、完成和开裁流程检查，合成测试不代表线上验收。
