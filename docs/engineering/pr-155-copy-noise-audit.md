# PR-155 业务文案降噪审计

## 目标
将正式业务界面中的调试、技术实现、内部版本、重复状态和旧流程残留文案移除或改写为业务语言，同时保持所有业务逻辑、权限、状态机、API 和 Root 绕过能力不变。

## 覆盖
- N02/N03 工序与 IE
- N04/N05/N06/N07 工作区
- 责任判定与老板签字
- 本厂承担审批
- 外部责任与扣款
- 全部订单与财务报表
- 工资管理
- 登录/身份提示
- Root 专属展示文案

## 重点清理
- 已加载责任版本 Vx
- 当前状态不在工序配置节点
- 订单版本 X
- Root 代上数 / Root 可代报 / 超级用户
- 服务端拟扣 / 浏览器传入 / 稳定游标等实现文案
- 旧责任处理等旧流程名
- 重复的“谁来处理 / 当前要做什么 / 完成后去哪里”说明

## 安全边界
- 不改业务状态机
- 不改权限和 Root 绕过
- 不改 API / DB
- 不改金额、工资、扣款计算
- 不改节点编号与真实业务流转

## 回归
新增 business-copy-noise contract，并同步依赖旧展示文案的 UI contract。CI / Full Gate 全绿后合并。
