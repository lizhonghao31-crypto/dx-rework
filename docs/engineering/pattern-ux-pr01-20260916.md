- 复用返工 `rework-detail-overview-grid`、`rework-detail-images`、`rework-workflow` 及紧凑样式，左资料右流程；760px及以下依既有断点上下排列、默认折叠。办理区仍在后方。

- 创建、资料更新、原单返工共用蓝底白字上传按钮；明确图片/PDF合计20份、保留资料计入总数、支持格式；大小限制读取现有受权接口，失败可重试，不冒充固定生产配置。
