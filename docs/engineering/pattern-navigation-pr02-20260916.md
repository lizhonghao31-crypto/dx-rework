## 已实现

- 标题左侧复用返工 `← 返回`；来源只接受看板、待办、工资列表及板房入口/价格页，非法 returnTo 回退到看板。
- 保存来源筛选、页码和历史记录中的滚动位置；列表数据就绪后恢复。创建成功以 replace 进入详情，不保留已提交表单为返回目标。旧创建查询书签仍兼容看板。
- 使用既有离开确认机制：空表单不提示；有修改时确认一次；上传/提交中不能离开；保存成功不再提示。类型切换、取消、标题返回、左侧导航和浏览器返回沿用同一守卫。
- 财务中心是展开式一级分组，其下仅工资管理，直接进入 `/ui/wages`；旧 `/ui/finance` 进入同一页并执行同一授权。桌面顺序按最新决定，顶部三个入口和移动四项＋更多不变；手机更多内也提供财务分组。
- 工资会计沿用 `wage_month_close_accountant` ＋ `wage:view`；菜单与 AuthGate/后端原权限一致。未添加 role/capability、未赋权真人，未复制工资模块。
- 已核实截图三是 `/ui/pattern-room` 的模块入口页，不是独立手机模板。创建/删除改用站内导航，保留历史状态，并忽略已中止的旧详情/列表响应。详情按订单路由重挂载，避免跨订单残留。
