# R5-03 原生制作与整件返做

依据已批准完整 v2 与九 PR 执行表 R5-03。当前为本地准备，正式提交须接入 R5-02 实际合并基线；本记录不代表远端 PR、Review、Full、合并或部署。

整件复版需要再次车板时，在原业务事务内复用原制作返工生命周期，生成待主管核定金额的新制作轮。完整修订资料保留，不用自动生成的旧资料替换用户本次修改。主管必须明确填写金额，0元也填写；车板完成与最终设计确认绑定实际制作轮，不能沿用第一轮已完成状态跳过本轮制作。原独立返工、派工、工资金额、财务权限和大货已实裁守卫保持。

旧尾查退回按当前实际任务办理权及同事务已保存的退回事实产生待核价制作，不授予尾查人员独立返工或核价权限，也不返回制作财务详情。首次原执行若在后续开发轮才真正提交，原提交事件记录当时轮次；已有无凭据关联不倒补。明确沿用完成车板、工艺布片、局部补做各走原范围，不自动重复计薪。历史第二轮异常不凭备注补造执行段或工资。

原发布页面及继续草稿页面均以有效执行报价控制发布按钮，读取中、失败和未配置时不能发布；原处刷新成功后恢复。保存草稿不依赖报价，已发布单的正式订单确认和工艺布片例外保持。此项只修实际功能状态，未按尚未取得的六张效果图重做视觉。

定向结果以 construction-evidence 中准确输入及原始报告为准：24项完整原生技术／返做检查、5项原App认证与价格交互、23项单元通过；另一个9项定向报告包含3项旧路线及6项已在技术组覆盖的交叉反例，不重复相加。7元返做合计17元，0元返做仍为10元；执行段与工资页、全范围合计和完整导出一致。原任务／轮次、重复提交、局部补做、真实PLT继承、原App草稿与同会话撤权同时保留。

旧完整链直接运行含PostgreSQL15+语法的历史初始化，因此本地PG13初始化失败不算执行业务用例；该链使用现有PG16.14二进制的新隔离低权限标记库定向验证。原App另在PG13.23隔离库验证。曾误取历史任务和隐藏章节的测试失败均保留，修正测试选择而未放宽业务条件。无现场数据、配置、生产部署或最终视觉验收。
