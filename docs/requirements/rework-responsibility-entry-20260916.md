# 返工责任结果与重新判责入口收口规则（2026-09-16）

状态：业务负责人已确认。

## 目标

- 返工详情顶部不再常驻展示“责任结果”大卡片，也不在顶部提供第二个“重新判责”入口。
- 责任相关操作统一收口到页面下方办理区附近，减少同一节点上下重复按钮。
- 责任历史继续保留，但默认折叠展示，不删除责任版本、重判原因、老板确认及已扣款历史。

## 入口规则

1. 若当前账号在外部责任台账中已有可用的“重判责任”申请入口，则不再同时显示整单直接重开按钮。
2. 若下方外部责任台账没有可用的重判入口，而当前账号仍具备既有整单重新判责权限，则保留整单重新判责作为下方兜底入口。
3. 不修改任何既有后端权限、审批规则、状态机、金额、工资或已扣记录。
4. Root 既有绕过能力保持不变；本次只收口展示位置和重复入口。

## UI

- 责任历史放在详情内容末端，默认折叠。
- 不再显示顶部“责任结果 / 本厂金额 / 外厂金额 / 实际已扣”等重复摘要。
- 重新判责仍要求填写原因，原有幂等与并发校验保持不变。
