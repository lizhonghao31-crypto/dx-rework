# 1.0 上线前 Root UAT：收货历史补录

状态：已确认  
确认日期：2026-08-25  
适用范围：Root 云窗口验收 PR-05

## 业务目标

仓管漏录历史收货订单时，可直接从收货页补回最近两天的真实收货记录；补录不追加到当前收货订单。

## 已确认规则

1. 保留现有“＋ 点击收货”入口，并在其下方增加“补录”按钮。
2. 点击“补录”复用现有收货表单，仅增加“收货日期”。
3. 可选日期仅为昨天和前天；今天继续使用普通收货，超过两天不能补录。
4. 补录形成独立收货批次，不向当前同款收货批次追加记录。
5. 补录沿用现有款号、数量、图片、幂等、仓管权限和操作审计规则。
6. 服务端必须独立校验补录日期，不能只依赖页面日期范围。
7. 补录记录按选择的业务日期进入收货看板；审计事件仍记录实际操作者、请求 ID 和实际操作时间。

## 明确不在本次范围

- 不允许补录今天或两天以前的日期。
- 不新增独立页面、角色、权限、表或迁移。
- 不修改订单看板的修改、删除或返工入口。
- 不把“补录”实现为修改累计总数或覆盖既有不可变收货事实。
