# 订单详情目标布局（2026-08-19）

本轮仅重构订单详情页展示骨架，目标是对齐已确认的 PC / 移动端效果稿的信息密度与主次关系。

## 不可触碰边界
- 不修改流程状态机、节点编号、权限判断、业务工作台内部逻辑。
- 不删除历史字段、验货报告数据、附件或审计记录。
- 不修改 N01-N10 服务端流转规则。

## 目标骨架
1. 顶部显式核心信息卡：返工工序、加工厂、发起时间、发起人、订单跟单；PC 补充附件数量。
2. 验货报告默认折叠，仅显示一行摘要。
3. PC：订单图片与订单流程左右并列，减少垂直滚动。
4. 移动端：核心信息双列；订单图片横向紧凑；流程节点横向滚动并保留真实 N01-N10 编号。
5. 当前工作区保持原业务组件，只调整外壳与标题层级。
6. 清除上一版依赖 nth-child / display: contents 选择业务字段的布局补丁。
