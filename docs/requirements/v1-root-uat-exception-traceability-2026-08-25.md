# 1.0 上线前 Root UAT：异常事实追溯

状态：已确认  
确认日期：2026-08-25  
适用范围：Root 云窗口验收 PR-04

## 业务目标

让系统管理员在不接触敏感信息的前提下，直接看清系统异常关联的订单、业务动作、失败阶段、最近错误、请求 ID 和当前处理状态；页面请求失败时保留可复制的请求 ID，便于按日志继续定位。

## 已确认规则

1. 复用现有“系统管理 / 系统异常”页面和现有异常事实来源，不新建监控平台或异常主表。
2. 异常记录补充关联返工单、业务动作、失败阶段、请求 ID、最近错误和当前状态。
3. 能可靠关联返工单时提供“进入返工单”入口；不能可靠关联时明确显示未关联，不猜测订单。
4. 管理页面 API 请求失败时显示服务端错误说明及请求 ID，并提供复制按钮。
5. 继续沿用现有系统管理员 / Root 读取权限，不扩大异常数据可见范围。
6. 错误摘要必须清理密钥、令牌、连接串、手机号和身份证号；详情只保留既有安全技术事实。
7. 只做事实追溯，不自动判责、处罚、关闭异常或增加新的重试能力。

## 明确不在本次范围

- 不采集新的通用 500 异常表，不建设告警、监控或自动处置平台。
- 不修改消息重试、钉钉投递、导出任务、附件上传或业务订单状态机。
- 不在错误详情中展示手机号、身份证、钉钉凭证、数据库连接或其他秘密。
