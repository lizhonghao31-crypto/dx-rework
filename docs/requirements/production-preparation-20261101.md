# 本轮产前准备规则（PR05 / 0270）

依据：`new-flow-20261031-approved-plan.md` 的 PR05、F.5、H，以及用户对本轮8PR方案和末尾修订的批准。适用于已明确采用本轮规则的订单；新单通过原创建事务采用，在途须主跟单确认当前资料预览、供应链总监/老板/Root明确采用。原资料、已完成实绩及原时效保留。2.0继续不做BOM。

- 设计引用本轮实际发布资料交给订单跟单；订单跟单记投料。预下单可以先投料，不要求预算、完整尺码或正式订单已经齐备。原主跟单存在时不能另指定第二位交接责任人。
- 设计开发工作台 v11.5 的新编号草稿只供保存和恢复。发号不等于业务生效，未发布不得交接、投料、发起报价或安排开发任务。预下单发布原子保存该版资料并向有效跟单交接，发布和实绩保有自己的实际日期。沿原审核确认正式订单成功时才以该真实时点首次采用原 A/B 时效。确认前已完事项不补造时点或催办，确认后未完工作仍须满足原前置。原预下单入口与历史记录不变。新创建界面与写入口待后续联合验证启用。见 [X2 执行记录](../engineering/workbench-v115-x2.md)。
- 仓管记主料、辅料、款号唛的实际到仓、款色数量及原凭证。原派工已指定的仓管为真源，早期可由管理岗位明确指定本单仓管。对色由设计既有选择决定，确认人按真实岗位明确指定；未指定时保留待分派，不让跟单重复选择是否对色。没有新增工厂签收入口。
- 实际记录追加版本；未知、撤回、部分备齐分别保留。文件就绪、当前物料适用性及本单范围共同决定是否有效，不能用一张设计图代替实物记录。更换材料后应核对本轮适用性，原收料历史仍可查。
- 草稿可提前写。对应主料首次可信到仓（含已开始的部分到仓）启动到仓后24小时协同目标；不以晚补料或派工刷新。最终发布在本轮主料可用、最终客户批复、有效技术尺寸复核及适用尾查/复版依据齐备后另计24小时。最终前提缺失时显示等待；不吞掉已经开始的草稿目标。缺可信时间仅限制评价，不能补造起点。
- 订单跟单在原制单保存、发布和交付。正式发布事务再次核 PR03 的有效技术 revision，并核对实际采用的尺寸表；界面可明确采用当前技术表，原其它制单字段继续使用。技术资料或物料并发变版时拒绝旧提交。对外交付引用具体已发布版本、接收人和实际交付时间，系统不替用户发送外部消息。
- 纸样和唛架共用原正式制单发布起点，合计默认48小时，来自订单冻结的面板参数。派工、查看、补料不重置。未完成准备在同轮制单换版时继承原时钟；原范围已完成后产生补做，保留原完成时效，不自动再给48小时。原面板显式应用后才改变相应未完成窗口。
- 普通/急单均可先做不受欠辅料影响的部分，登记款色、已做和待补物料。局部记录不写整单完成事实，不放行整单。补料提醒按本准备范围归并一条仓管待办，补到后沿原技术任务复核补做，不重复建任务或重复计件。
- 款号唛是对应开裁款色所需的实物，数量须覆盖本次实裁范围。纸样可先做，实际开裁仍沿原有效技术、适用验布/预缩、老板批准等条件。款号唛条件不塞入工厂后续生产的全局门槛。
- 验布失败不停止已开始的时钟，质量放行仍沿原报告与授权决定。原验布接口和新物料办理共用实际到仓版本；到仓订正后须重新核验该版，旧质量报告不能自动放行新到仓依据。
- 高温适用、经纬缩率、报告及预缩方法沿技术原物料依据保存；仓管办理不代技术确认。未知不等于无需。针织须专业预缩，不用常规混洗代替；本期不新增BOM表或独立供应商端。

## 历史和职责边界

旧制单72小时及已完成纸样唛架保留原快照。在途迁入保留原已保存/发布的事实及采用技术版本；后续新技术要求重新核对，不给历史批量盖章。旧下游合同业务时钟、真实回货、QC返工/本厂做尾、装箱和船样原规则继续使用。PR06才处理工厂F02/F03退役与QC进度，PR07/08处理目录和材料一览。

接口使用原鉴权、同单范围、追加版本和幂等。读取、下载、存草稿、已读均不采用排程、不制造实际完成、不修改客户约定日期或计划日期。

## 本轮审查补正

- 款号唛只接受明确计件单位（枚、个、件，保存统一为枚）。箱、包、米没有默认换算，不能加入可开裁件数；历史未知单位不计为可用数量，历史原值保留。
- 到仓追加订正与预缩任务条件在原事务内同步；预缩完成再次读取当前质量事实，不能信任此前放行留下的任务状态。尾查和设计确认复版依据也在原命令事务中刷新正式制单窗口。复版确认发生于设计实际执行该确认命令的业务时间，不取附件上传或仓库验布的旧时间。
- 面板应用记录明确当时已有的未完成任务；原任务的应用不自动覆盖后来新增补做。已明确应用的同一未完补做换版时保留起点和应用范围；新补做无明确期限仍显示未设置。订单SLA读取沿用同一纸样窗口计算，不再以旧整单应用覆盖该结果。
- 物料、人员、交付、历史采用各自保留编辑状态和提交快照；保存一项不抹掉其它项草稿。结果未明使用不可变原内容和原标识恢复，不能刷新后换版本再次新增。实际父工作区的返回、刷新与浏览器导航共同保护未保存输入，写入或结果未明时不能卸载。
- 本次不按“包装”等物料名称推断纸样适用性或自动豁免。缺辅料可登记实际已做和待补范围；整项完成仍核当前明确的适用范围和物料依据。款号唛开裁检查单独保留，不将局部准备当成整单开裁许可。

同一未完补做窗口在中途换版后才明确采用期限，该应用仍随该窗口后续换版保留；不能只认最初/当前两个任务ID而遗漏中间版本。完成该范围后新增补做是独立窗口，不能继承此前完成范围的应用。
