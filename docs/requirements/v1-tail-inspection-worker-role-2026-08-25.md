# 1.0 上线前：尾查使用通用工人角色

状态：已确认  
确认日期：2026-08-25

## 业务规则

1. “尾查”工序及其报数、核量和工资事实全部保留。
2. 不再要求为尾查工序单独授予“尾查”角色；所有当前有效的内部“工人”均可被选择执行尾查。
3. 工人仍只能查看和提交分配给本人的任务，不能因具备工人角色查看或代报其他人的尾查任务。
4. 权限管理不再提供新的“尾查”角色选择；既有底层角色与历史记录仅保留兼容，不改写历史事实。
5. 临时工规则不变；本次不把无登录角色的临时工扩展为尾查执行人。

## 施工边界

- 不删除尾查工序或 `tail_inspection` 执行类型。
- 不修改工序配置、单价、工资、最终数量确认和历史尾查记录。
- 不新增页面、UI 组件、角色或数据表。
