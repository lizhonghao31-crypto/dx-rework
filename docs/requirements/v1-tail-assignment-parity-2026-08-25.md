# 1.0 上线前：尾查分人方式与普通工序统一

状态：已确认  
确认日期：2026-08-25

## 业务规则

1. “尾查”继续作为固定特殊计件工序存在，不恢复独立流程节点。
2. 尾查人员分配复用普通工序的“选择本单工人”交互，不再使用尾查专属搜索框和固定复选框名单。
3. 候选人员与普通工序一致：当前有效的正式工和临时工均可选择；不再依赖“尾查”角色。
4. 正式工只处理和报数分配给本人的尾查任务；临时工尾查由尾部主管按现有临时工代报逻辑上数。
5. 已分配人员继续保存姓名和人员类型快照，尾查单价、IE 核价、计件、最终数量确认及工资逻辑不变。

## 验收口径

- 桌面端和移动端尾查均使用与普通工序相同的选人弹窗与已选人员展示。
- 弹窗按“正式工 / 临时工”分组，可搜索、增删并确认本单分工。
- 尾查至少选择 1 人；无效或停用人员仍由后端拒绝。
- 既有历史尾查角色和历史订单保持兼容。
