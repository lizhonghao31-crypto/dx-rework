# 1.0 上线前：仓库收货次品数量

状态：已确认  
确认日期：2026-08-26

## 业务规则

1. 仓库收货在“实际收货数量”下方增加“次品数量”。
2. 次品数量是本次实收数量中的次品件数，默认0，只能填写整数，且必须满足 0≤次品数量≤实际收货数量。
3. 每次收货独立记录次品数量；同一收货批次多次收货时，订单看板累计显示。
4. 历史收货记录的次品数量兼容为0，不改写既有收货事实。
5. 原差异口径继续为“实际收货数量－收货单数量”，次品数量不参与差异计算。
6. Root在尚未发起返工前修改收货订单时，可以同步修正次品数量；原始收货事实继续不可修改。
7. 本次不新增次品KPI，不自动创建返工单，也不改变权限。
