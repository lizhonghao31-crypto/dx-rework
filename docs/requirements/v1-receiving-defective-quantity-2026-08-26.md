# 1.0 上线前：仓库收货次品数量

状态：已确认  
确认日期：2026-08-26

## 业务规则

1. 仓库收货在“实际收货数量”下方增加“次品数量”。
2. 次品数量是本次实收数量中的次品件数，默认0，只能填写整数，且必须满足 0≤次品数量≤实际收货数量。
3. 每次收货独立记录次品数量；同一收货批次多次收货时，订单看板累计显示。
4. 历史收货记录的次品数量兼容为0，不改写既有收货事实。
5. 原差异口径继续为“实际收货数量－收货单数量”，次品数量不参与差异计算。
6. Root在尚未发起返工前修改收货订单时，可以同步修正次品数量；原始收货事实继续不可修改。
7. 本次不新增次品KPI，不自动创建返工单，也不改变权限。

## 2026-10-18 实收标签展示补充

- 同口径实收总量（包含次品）的标签右侧统一显示“含次品数”，覆盖录入、列表、指标、历史、编辑/修正、处理快照及明确关联的返工/生产回货展示。未接入路由的现存回货分析组件同步文案，不因此新增入口或授权。
- 提示字号为 `min(原标签字号, max(10px, 原标签字号 - 3px))`：14px 配11px；手机原标签9px时提示同9px，用既有浅灰提示色和正常字重区分。原标签和数值字号不放大或缩小；窄屏保留完整数字及单位。
- 次品独立量、良品、送货单、装箱、实裁、生产/返工/工资报数、订单/记录次数、日期及金额不套用此提示。接口、计算、统计口径、历史事实、导出数据结构和权限保持原样。


## 2026-11-15 订单回货卡片正品数量

用户经 Dot 明确要求 main 收货看板订单卡片将“实收 含次品数”改为“实收 正品数量”，数值也须为正品。卡片正品 = 同一稳定分组、同一观察范围的累计实收 − 累计次品；日期筛选截至期末，款号搜索沿现有全历史范围，并沿现有 Root 更正/合并事实还原对应观察时点。不能用本期次品减累计实收，也不能拿未来或当前全量次品减历史实收。全次品显示 0，缺少新投影时显示未知，不伪造正品。

此处“正品”只表示原实收扣除已登记次品，不代表新增 QC、洗水或装箱放行认证。顶部“期间实收数量 含次品数”、搜索实收汇总、次品列、历史/录入/更正、导出列及原差异计算保持原有口径：收货差异 = 累计实收（含次品）− 送货单数量，装箱差异沿原含次品实收比较；不借本次修改数量事实、权限、判断或处理快照。
