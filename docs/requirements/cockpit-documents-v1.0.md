# 座舱相关资料目录 V1.0

2026-10-19，按本轮已批准方案保留十一主类：开发单、样衣打板执行单、关联打板杂事单、订购信息与 PO、预算单、大货制单、外发合同、大货产前准备、裁床单、裁后工艺与发厂资料、回货与装箱资料。目录不列外发申请、工厂生产单、返工与本厂做尾；原业务与小节点入口不删除。所选节点仍保留其已授权的原业务记录入口；只读引用不等于判定该用户没有原模块办理权限。

分类与版本均按需读取。没有确定业务来源、权限拒绝、未创建及不适用分别处理；成功但缺必需字段不能当作未创建。开发数字轮次、打板 UUID 轮次、预算及制单发布版本保持不同含义。历史读取失败不改开最新版。目录展开状态通过原返回上下文恢复。

原模块读取器继续核权。预算沿独立 budget 权限；合同目录在任何版本和附件元数据查询前要求原 supplier_contract_data:read（Root 保留特权），再用原外发单可见范围读取。下载继续使用原附件绑定与权限。杂事只按明确 source/PO ID，收货只按批次与真实裁床分组；不按文字款号猜关联。

合同按 contract document ID 归属历次回签 revision 和附件，审批 decision version 不作 PDF 版本。读取完整回签目录不改变原上传上限、审批、生成或监控时钟。两文档各两修订是读模型与浏览器合成夹具；隔离 PostgreSQL 原服务覆盖实际两版各一次回签，原总文件上限仍为两件，不宣称已通过原写入器上传四件。

原件已停用或不可用时无下载链接。裁后物流、检查复查、装箱与结案按原业务记录展示，不虚构 PDF。创建、修改、发布信息只取对应原字段；缺失明确未记录，不从节点负责人或完成时间补造。历史开发轮次元数据取该轮 revision，不能沿用初版编辑人。

新增三个只读入口：pattern-room/related-orders（持久化原打板 scope、分页）、sourcing/cases/:id/contract-directory（合同资料权限与原单范围）、receiving/batches/:id/document-history（原收货读取授权、真实批次/裁床组）。不新增迁移、业务写入或附件存储。
