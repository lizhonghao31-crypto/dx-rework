# 1.0 上线前 Root UAT：N02 人员边界与临时工资料补录

状态：已确认  
确认日期：2026-08-25  
适用范围：Root 云窗口验收 PR-03

## 业务目标

让尾部主管清楚区分“本单分工”和“以后订单的默认名单”，并能在 N02 分工现场补齐已选临时工资料，不离开当前订单。

## 已确认规则

1. N02 增加、移除或确认人员只修改当前订单快照，不自动回写公共工序默认名单。
2. 本单入口文案为“选择本单工人”；只有明确点击“保存为默认名单”才更新以后订单的默认候选人。
3. 已选择临时工的姓名可点击；点击后复用现有临时工小弹窗，不新增独立页面。
4. 编辑时姓名预填且不可修改，只能补录或修改手机号、身份证号和现有备注。
5. 保存后关闭弹窗并停留在当前 N02 工序，不跳页、不刷新整张订单。
6. 仅尾部主管、老板和 Root 在同时具备临时工管理及隐私资料权限时可读取或修改完整资料。
7. 服务端和数据库共同校验资料格式、人员类型、有效状态和审计上下文；不能通过直接 SQL 绕过受控更新。
8. 操作日志不得保存手机号、身份证号或备注正文，只记录对应资料在更新前后是否存在。
9. 继续使用现有字段，不新建表，不改变临时工工资倍率、任务分配或其他工序流程。

## 明确不在本次范围

- 不建设临时工资料管理页、批量导入、历史资料回扫或重复人员合并。
- 不修改正式工姓名或钉钉人员主数据。
- 不自动保存全局默认名单，不调整收货、附件、异常追溯或性能逻辑。
