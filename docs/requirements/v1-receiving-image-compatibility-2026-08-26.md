# 1.0 上线前：仓库收货图片兼容

状态：已确认  
确认日期：2026-08-26

## 业务规则

1. 仓库收货必须支持手机相册中由微信保存、且浏览器能够解码的图片。
2. 标准 JPEG、PNG、WebP 继续沿用现有快速上传路径。
3. 服务端认定图片内容与声明类型不一致时，仅对当前收货图片在浏览器端重新解码并转为标准 WebP 后重试一次。
4. HEIC、HEIF 等相册图片在浏览器能够解码时先转为标准 WebP，再进入现有上传链路。
5. 服务端文件内容安全校验、收货图片数量、首次必传和同款追加复用规则保持不变。
6. 仍无法解码的图片显示中文错误，不向仓管暴露英文底层错误。
