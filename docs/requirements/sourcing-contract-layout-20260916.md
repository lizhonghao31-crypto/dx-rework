# 外发加工合同 PDF 版式优化规则（2026-09-16）

状态：业务负责人已确认。该文件仅冻结合同 PDF 版式，不改变合同字段、条款、审批、工艺来源或供应商资料逻辑。

## 版式规则

- 合同标题在正文有效宽度内居中，适当增加字间距与标题下方留白。
- 合同编号、生成日期、签订地点放在标题下独立信息行，整组居中并保持均匀间距。
- 顶部甲方、乙方名称继续各占一行、左对齐，但与合同信息和加工明细之间增加清晰间距。
- 加工明细表头居中；日期、数量、单价、金额等结构化字段水平居中；单元格内容垂直居中。长款号、长名称允许自然换行，不以缩小字体强塞。
- 正文条款继续左对齐；“三、质量要求”标题与其多行正文分层显示，其余条款保持紧凑可读，避免无意义大留白。
- 第二条红色“工艺及承包范围”继续直接读取生产管理节点 3 的有序确认结果，颜色及业务逻辑不变。
- 底部签署区调整为甲方左栏、乙方右栏，中间保留明显间距。甲乙方名称、地址、代表、日期分别对齐；乙方收款人、开户行、银行账号独立成行。
- 页脚合同编号与页码居中。
- 多款、多行、长地址和跨页合同必须保持无重叠、无裁切、无破坏性缩字。

## 明确不变

- 甲方公司名称和地址继续由合同模板自动带出，不增加订单级甲方主体录入。
- 甲方代表继续保留线下签署空白线，不新增系统填写入口。
- 合同字段、金额、条款文字、审批、正式派单、供应商资料与权限均不因本次版式优化改变。
- 已经生成并留存的历史 PDF 不追改。
