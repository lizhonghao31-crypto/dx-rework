# 供应商合同签约名称选填规则

状态：2026-09-16 业务负责人已确认；本文件作为 `sourcing-supplier-production-v1.0.md` 的增量业务决定，相关旧表述与本文件冲突时以本文件为准。

## 最终业务规则

- 原字段 `contractEntityName` 对一线文案统一表达为“合同签约名称（选填）”。
- 仅当实际合同签约名称与供应商名称不同时填写该字段。
- 该字段留空时，系统自动以供应商名称作为合同乙方名称。
- `contractEntityName` 留空不再计入供应商“合同资料缺项”，也不得阻断合同 PDF 生成。
- 已有明确填写的合同签约名称继续优先使用，不覆盖、不回写为供应商名称。
- 已生成合同 PDF、已冻结历史合同事实不追改。
- 尚未生成且仅因 `contractEntityName` 被旧规则标记为缺项的合同，应解除该缺项；若无其他缺项，可继续进入原合同生成流程。
- 批量录入中该字段继续允许留空；模板必须明确提示“仅与供应商名称不同时填写，留空自动使用供应商名称”。

## 不在本次范围

- 不改变供应商名称本身的录入规则。
- 不改变乙方代表、地址、收款人、收款账号、开户行等字段现有规则。
- 不实施财务发起供应商日常资料补充/修改申请；该事项后续单独建设。
- 不改变供应商新增审批、正式维护权限、合同审批或正式派单流程。
