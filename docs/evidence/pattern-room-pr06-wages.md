## 实现

0179 新增不可变板房有效工资来源，一执行段一稳定工资 ID。满足交接、取消费用确认，或杂事完成/停止及工时核定条件的同一事务中，通过 PostgreSQL statement transition table 一轮一次写入。迁移补齐此前已具备资格的板房执行段；不复制旧工资或重开历史月结。首次/返工/杂事沿用 0062 的 round(整组,2)、trunc(各份,2) 与最大余数分币；重复人员以真实 person_id、segment_id 稳定排序，不借助浮点数或虚构人员。零元或分币后为零不产生待结清行。

月份来自执行段真实完工/停止时间，业务时区 Asia/Shanghai；释放时间独立保存。已计薪执行段和轮次计价/完成事实受到数据库保护，普通业务不能覆盖工资。原有取消后的杂事确认可继续，不改变已产生的工资快照。

扩展原 wageSelection、rework_wage_settlement_marks 与原 API，保留旧普通工资和历史月结路径及 ID；不伪造 rework_order_id。所有来源统一筛选、金额汇总、人员汇总、导出、完整预览及标记。按来源+真实订单 ID 去重，板房轮次数、工资条数单列。500 条仅为页面预览上限；现有导出超过 50,000 条明确报错，提示缩小筛选，绝不静默漏行。

保留原工资管理页面/CSS、Button、InsetField、Surface、StatusBadge、ListPagination、平台确认框，增加来源、类型、历史月份与状态条件。主汇总为工资/未结算/已结算；人员可展开来源构成，费用可展开轮次、执行段、释放和标记依据。财务取得最小工资依据，不获得板房 PDF/制作资料权限。新增板房金额显示最多三位小数，工资最终分币值保持原两位规则；XLSX 保存原十进制数值并对板房依据使用三位显示格式。
