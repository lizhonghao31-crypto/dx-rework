## 结果

仅样衣财务与可信 Root 可单件/批量登记。采购日期、精确金额、小票及当前企业有效员工必填；初始持有人默认采购人，也可选择不同员工。编号按服务端上海月份生成，事务内串行分配。主档、财务、小票/图片绑定、首次领用与审计同时提交；一件失败整批回滚。

首次状态为借出中，用途固定“采购后直接开发/打板”，不要求扫码。重复提交复用同一结果，改变内容必须使用新的提交编号。批量可共用小票；小票与普通图片不可混用，绑定后的通用下载与样衣详情下载均检查样衣角色和财务权限，包括上传者降权后的访问。

新增写入开关默认关闭，切换前不开放建档；开放手续与核心对账属于 PR-5。附件上传复用平台 OSS 签名、图片处理和完成校验，不另建公开凭证通道。

## 验证

定向单元测试覆盖严格字段、金额、小票、公私隔离及批量上限；SQL 集成测试覆盖事务回滚、首次领用、共享小票、有效身份、重复提交、权限隔离，以及真实 PostgreSQL 并发编号/重试。该 SQL 套件加入现有 Full Gate 业务链列表。
