# 订单完成后扣款与工资只读纠偏证据（2026-09-05）

## 业务结论

- “未开始”只用于订单尚未完成。
- 订单完成即进入扣款；未全部结束时统一显示“未扣款”。
- 订单完成且相关扣款流程全部关闭后显示“扣款完成”。
- 完成订单即使尚未生成扣款记录，也必须显示“未扣款”，不得显示“未开始”。
- 工资金额仅供财务查询、对数和导出，不设置工资核对、月结、会计锁定、待办或阻断。

## 实施范围

- 修正管理卡片扣款状态 SQL 映射。
- 订单详情移除工资结算进度和会计锁定文案，完成节点只展示扣款状态。
- 工资页面固定为只读查询/导出。
- 停用工资月结 HTTP 写入口；历史工资表、已存在记录和工资计算保持不变。
- 更新当前返工 Golden Source、流程治理、ADR 与自动化测试。

## 禁止范围

- 不修改工资金额计算、责任金额、实际扣款金额或历史账。
- 不做数据库迁移，不删除历史工资期、关闭记录或审计事件。
- 不改变现有 UI 组件库、调色盘或详情页原有跳转方式。

## 验收

- Full Gate 必须在当前 Head 全绿。
- 已完成且无扣款记录的订单显示“未扣款”。
- 未完成订单显示“未开始”。
- 全部扣款流程关闭后显示“扣款完成”。
- 页面及公开路由不存在工资月结或会计锁定操作。
